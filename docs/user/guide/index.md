# 使用 Coding 界面

浏览器使用方式请按[根目录 README](../../../README.md#run) 启动 Web UI，命令会打印访问地址；macOS arm64 桌面端由 [Electron 应用](../../../apps/desktop-electron/README.md)提供。本指南从界面已经打开的状态开始。`dsh` 进程会把启动时所在的目录作为默认文件系统位置；全新的界面不会选中任何 Workspace。

macOS 桌面窗口打开时默认最大化，不会进入全屏。双击顶栏空白处可在最大化与还原之间切换；还原后拖动空白处可移动窗口。顶栏按钮和输入框仍可正常操作。

没有保存语言偏好时，界面默认使用中文，不随系统或浏览器语言变化。可在**设置 → 通用设置 → 语言**选择 English；本机连接时选择会保存，后续打开继续使用所选语言。

## 配置模型

没有可用默认模型时，首次欢迎引导会打开提供方与模型配置：选择已有的可用提供方和模型，或添加提供方及至少一个可用模型，再选定默认模型并点击**开始使用**。引导不能跳过；若加载或保存失败，按弹窗提示重试或修复配置。已有可用默认模型时不会显示该引导。之后可在**设置 → 模型**修改提供方与模型，在**设置 → 图片识别 Fallback**配置纯文本模型处理图片所需的视觉模型；模型变更在下一次请求时生效，无需重启服务器。

[模型配置指南](./providers.md)介绍其他提供方和自定义 OpenAI 兼容端点。

在已有普通会话的输入框中，收起的入口显示当前模型和推理等级；点击后底部入口显示**选择强度**并打开滑块。拖动时上方档位名称和颜色即时预览，松开后提交当前模型适配器提供的等级，右上角可重置为默认值。点击滑块上方的模型名称可打开并排的渠道与模型列表，左侧选择渠道，右侧按名称或 ID 搜索并选择该渠道的模型；当前模型没有可调等级时会直接打开模型列表。选择从当前会话的下一次模型请求起生效，运行中的请求不变；同时会尝试保存为新会话默认值，保存成功后新会话也采用该选择。输入 `/model` 也可切换模型，切换后采用该模型的默认推理强度。

## 配置联网搜索

`web_search` 默认使用免费的 DuckDuckGo 搜索，不需要 API 密钥。在**设置 → 联网搜索**可选择 DuckDuckGo、Tavily（`tavily`）或 DeepSeek（`deepseek-official`）；该选择只影响联网搜索，不改变对话模型。选择 Tavily 时，在该页保存独立的 `TAVILY_API_KEY` 凭据；DeepSeek 搜索使用独立的 `DEEPSEEK_SEARCH_API_KEY`，不使用对话模型的 `DEEPSEEK_API_KEY`。所选提供方缺少凭据或搜索失败时会直接报告错误，不自动切换到其他提供方。

各提供方的 HTTP(S) 前向代理在**设置 → 联网搜索**分别配置，互不共享。DuckDuckGo 只有代理地址；Tavily 还可修改默认 `https://api.tavily.com` 的 API 基址；DeepSeek 还可修改 Anthropic 兼容 Messages API 的基址，默认 `https://api.deepseek.com/anthropic/v1`。端点、代理和凭据的详细配置见 [DuckDuckGo](../../../packages/web/web-search-duckduckgo/README.md)、[Tavily](../../../packages/web/web-search-tavily/README.md)和 [DeepSeek](../../../packages/web/web-search-deepseek/README.md) 搜索提供方。

## 选择开始方式

点击**选择工作区**即可搜索已列出的 Workspace。若要在本地项目中工作，可选择已有 Workspace，或选择**打开文件夹**并选取项目目录。Session 打开后，编辑器即可使用。

选择**不在项目中工作**会在 Host 用户 HOME 目录创建 Session，但不会注册 Workspace。只有没有当前 Session 时，编辑器才不可用。

新对话欢迎页右上角有两个面板按钮：左侧打开或收起横跨主内容的终端底栏，右侧打开或收起整个右侧边栏。进入具体对话后，两个开关仍在对话页头右上角；工作台顶栏可关闭工作台，接管对话区时还可从顶栏切换终端底栏。页头和欢迎页的右侧按钮提示为“打开右侧边栏”或“收起右侧边栏”，再次点击会收起整个右栏；关闭右栏不会收起已打开的终端底栏。右侧按钮不控制左侧导航栏；通过欢迎页按钮打开一个面板时会收起另一个，再次点击则关闭该面板，不折叠导航栏。工作台中的普通面板开关可以同时显示两个面板。

直接打开工作台会显示**审查、终端、浏览器、文件、侧边聊天**五项功能；审查和侧边聊天标记为未接入。选择**终端**会在右侧新建可输入命令的终端标签；每次选择**浏览器**会新建一个空白页面；选择**文件**会创建或切回该 Session 唯一的文件管理器标签，点击树中的文件则打开独立的文件预览标签。它们共用工作台顶栏的一行标签，点击标签显示对应内容；共享的 `+` 每次新增并选中一个“新标签页”，其内容区显示相同功能菜单，本身不直接新建页面或终端；选择功能后此入口消失，并打开或切换到相应标签，关闭入口只移除本地标签。“返回功能菜单”仅显示菜单，不新增“新标签页”。菜单出现时原有标签保留，可继续选择功能。右侧终端与底栏终端的进程和标签独立，可以同时使用。

已装配的 Client 插件也可在同一个 `+` 菜单增加入口，并在所属 Session 的右侧工作台打开自己的标签；没有此类插件时菜单仅显示上述内置功能。外部标签仍使用单个右侧面板，不提供分栏或浮动窗。

浏览器、待加载页面、文件、终端和外部插件标签使用一致的尺寸、文字截断和选中、悬停、聚焦状态。

工作台较窄时，文件预览标签独占内容区，不显示文件树；切回文件管理器标签，或从功能菜单选择**文件**，即可继续浏览目录。较宽时文件管理器和文件预览均显示文件树。

终端底栏的 `+` 可新建独立终端，点击标签切换；标签上的关闭按钮结束该终端。Shell 执行 `exit`（或当前 Shell 支持的 `quit`）并断开连接后，对应标签会自动关闭；意外断连仍可在原标签重连。最后一个标签关闭时底栏收起，再次打开会创建新终端。底栏右侧的关闭按钮只收起底栏，重新打开时仍可使用未关闭的终端。

切换右侧标签、切换对话或收起右栏与底栏时，已打开终端的进程和输出会保留。关闭终端标签会结束对应终端；关闭右侧的最后一个标签回到功能菜单，底栏继续按自己的状态显示。终端连接断开、移除对话或关闭应用后，原进程不会继续保留。

已有空白 Session 时，面板按钮会沿用该 Session；还没有当前 Session 时会先连接最近使用的 Workspace，没有 Workspace 则在 Host 用户 HOME 创建未分组 Session。发送第一条消息后，所选面板会在这次对话中保持打开。

在 Coding 桌面端中，选择**远程连接**，先选连接模式，再输入 SSH 主机、使用密码或私钥认证、确认未知主机密钥并选择远程目录。默认的**基础模式**只使用 SSH 与 SFTP，无需上传远端 agent 或允许 SSH TCP 转发；它支持远端目录浏览、文件读取／写入／编辑、`glob`／`grep` 搜索、前台与后台 Bash 命令、持久终端／PTY，以及 Code Mode 的 Bash 和远程文件工具。基础模式不支持 LSP；Windows 远端不支持基础模式的命令与 PTY 操作，执行请求会明确失败。

基础模式写入使用 SFTP：原子创建需要服务器支持 hardlink 扩展，覆写与编辑需要 `posix-rename@openssh.com`，缺少相应扩展会失败。按版本覆写会在提交前复核文件，但 SFTP 不提供原子的版本比较交换，并发写入仍可能发生在复核和发布之间。SSH 不提供前台进程组查询，终端的相应检查不可用；信号或终止请求不能保证远端进程树已经退出，状态不明时会报告失败，请检查远端状态后再操作。

需要 LSP 或 Go agent 提供的远端执行语义时，选择 **Agent 模式**。它也支持文件读写编辑、搜索、前后台 Bash、持久终端／PTY 与 Code Mode，会部署仅监听远端回环地址的小型 Go agent，并需要 SSH `direct-tcpip` 转发；目标侧不需要 Node。两种模式的 Code Mode 都经 esbuild 转换 TypeScript 并在隔离的 Goja 中运行，拥有声明的工具 binding，但没有 Node 内建模块、`process`、`require` 或 Host 环境；基础模式的 Goja 隔离进程在桌面 helper 本机，文件与 Bash binding 仍指向远端，不会回退到本机工作区或 Node worker。

两种模式的凭据都只保留在当前对话框／连接中，不会保存；未知主机密钥需要明确确认，已变更的主机密钥会使连接失败。应用重启后需要重新连接，才能复用已有的远程工作区；普通浏览器界面不能发起 SSH 连接。本地 Host 仍负责工具审批和持久 Session 日志。远程 Bash 需要使用**完全访问**（`danger-full-access`）；这不是远端沙箱。连接断开、marker 过期或所选模式不支持操作时，请重新连接或选择合适模式；操作会失败，不会改在本机运行。

## 运行任务

启动一个会话并发送：

> Summarize this repository and identify its main packages.

Agent（智能体）可以读取和编辑工作区文件、运行命令、委派工作并维护计划。如果根据当前权限策略，某项操作需要审批，Web UI 会先询问你。

### 让 Agent 使用浏览器

在本地 Session 中提出网页任务，例如“打开这个网页，读取标题并截取画面”。标准工具模式和 PTC／Code Mode 都通过 `browser_navigate`、`browser_snapshot`、`browser_click`、`browser_fill`、`browser_scroll`、`browser_screenshot` 和 `browser_close` 操作该 Session 的 Chromium 页面。成功导航后，当前 Session 的右侧工作台会自动显示 Agent 实际打开的页面，无需手动选择浏览器，也不会额外新建空白标签；桌面原生导航超时但安全停稳时，若 Host 标签仍在，也会展示该页面，操作本身仍报告失败。等待期间若你切换标签或收起工作台，手动选择优先。审批拒绝、无效导航、无法安全停稳的超时、其他工具结果和历史记录不会自动打开。预设提供按需加载的 [`browser-use` 技能](../../../packages/skill/skill-browser-use/README.md)：它指导 Agent 先观察页面，再使用观测中的元素引用操作；除非要求关闭，否则页面留在工作台供查看。技能不授予额外权限。当前会话使用**完全访问**（有效沙箱模式为 `danger-full-access`，有效审批策略为 `never`）时，操作无需逐次审批；`danger-full-access` 搭配 `ask` 仍需逐次审批，较窄权限搭配 `never` 则拒绝操作。审批拒绝、取消或没有可用响应时不会执行；具体权限规则见[浏览器工具](../../../packages/browser/tool-browser/README.md)。Web/CLI 使用 Playwright，源码开发及 CLI 首次使用前需备有匹配的 Chromium，可运行 `pnpm exec playwright install chromium` 安装，缺失时操作会报告浏览器不可用。桌面 Host 使用 Electron 窗口中的原生 guest，真人和 Agent 操作同一页面；桌面包无需另行安装 Playwright Chromium headless shell。

直接打开工作台并选择**浏览器**，每次选择会新建一个空白标签。在地址栏输入 HTTP(S) 网址或域名并按回车即可导航；工具栏可后退、前进和刷新。工作台顶栏可切换或关闭各页面标签；点击共享的 `+` 会选中新建的“新标签页”并显示功能菜单，再选**浏览器**才创建页面；仅返回功能菜单不会新建该入口或页面。文件管理器、文件预览与终端标签仍在同一行中。关闭最后一个浏览器页面后可继续使用其他类型标签；没有标签时回到功能菜单。

手动输入地址、刷新以及等待浏览器初始状态或已选页面时，加载动画位于地址栏，内容区不显示重复的加载提示；Agent 占用浏览器时仍有单独提示。桌面端的页面可能在可显示后继续加载，此时地址栏保留加载动画，直到页面停止加载。

普通点击或按 Enter 激活 Assistant 正文中的 HTTP(S) 链接，会立即展开当前本地 Session 的右侧工作台，在独立标签的地址栏保留完整目标网址并显示加载动画；内容区不会重复显示网址或加载提示。页面就绪后在该位置显示真实内容，不会弹出系统浏览器窗口。连续点击的链接各自打开，导航失败时地址栏仍保留网址，内容区显示原因和重试按钮，原有页面不受影响；浏览器服务不可用等尚未接纳的失败仍由对话页提示。这是人工操作，不使用 Agent 浏览器工具的审批；远程工作区不支持在本机打开该链接。

Web/CLI 可在截图上按位置点击、滚动，或先点击位置再输入文本；输入是在当前焦点处插入文本，不会替换输入框原有内容，也不提供任意键盘按键。桌面端可直接点击、滚动和输入原生页面，网页不是 renderer 的 `<webview>`。浏览器仅供已附着的本地 Session 在本机回环同源界面中人工控制；Remote-SSH 工作区和非本机访问不提供该操作。

Web/CLI 工作台在 Agent 导航、读取、点击、输入、滚动或截图后显示最近一次成功操作后的画面、地址及 Agent 动作的虚拟鼠标；画面随右栏可用尺寸等比缩小，通常以页面视口的双倍像素捕获，超出大小限制时回退到单倍像素。这是 Host Playwright 页面按操作捕获的 PNG 镜像，不是实时视频或可直接访问的网页 DOM；人工动作按页面视口坐标交给 Host 执行。桌面工作台显示实时的 Electron `WebContentsView` guest，Agent 与真人共享它；页面尚未在工作台显示时，Agent 可取得 DOM 观测而不捕获 PNG，明确请求 `browser_screenshot` 会报告不可用。页面呈现后显式截图可向模型提供并记录图像附件，桌面 Client 自身不显示 PNG 镜像。

Agent 浏览器操作从等待审批至执行结束期间，人工浏览器控件禁用，Host 也拒绝人工命令；桌面 guest 在这段时间暂不呈现以阻止页面内人工输入。网页在两次调用之间自行跳转时，Agent 下一次调用可针对新页面继续操作，并在需要时取得新目标的审批；等待审批期间网页再次跳转则本次操作失败，需重新调用，旧页面的元素引用不可复用。桌面原生导航卡住超过 10 秒时会尝试停止；若页面安全停稳，操作仍报告失败，但保留原页面供下次单独获批的快照查看；无法安全停稳则关闭该 Session 的浏览器。已呈现页面的截图若卡住超过 5 秒，也只关闭该 Session 的浏览器。切换到菜单、文件或终端标签、切换对话或收起工作台不会关闭页面；人工浏览器命令不使用模型工具的审批，也不改变 Agent 的浏览器权限。Agent 只能操作它从当前页面快照获得的元素引用，不能提交 CSS 选择器或网页脚本；完全访问同样遵守元素引用、目标身份与会话资源限制。桌面 Host 与主进程的私有连接中断或私有桥请求超时、取消时，浏览器操作失败并释放全部桌面浏览器会话，不会回退到另一个浏览器。

浏览器操作仅支持本地工作区及未选择工作区的本地 Session；远程 SSH 工作区会拒绝操作，不会转而访问本机页面。页面直接使用 Chromium 原生联网，可以访问公网、环回与私网服务，无需配置目的地允许列表；跳转与子资源不做目的地过滤，WebSocket 和普通服务工作线程可用。导航输入仍须是无用户信息凭据的 HTTP(S) URL；Chromium 的证书验证、同源与 CORS 等标准安全机制保持启用。浏览器不支持下载、弹窗或授予页面浏览器权限。工作台状态与截图的 Host API 仍只供本机回环同源界面访问，这不限制页面的出站网络。

Chat 视图左侧的细轨标出已加载的用户消息和中途引导消息，阅读时会突出当前位置；悬停或键盘聚焦可预览消息，点击或键盘激活可跳回对应位置。较窄的窗口改用紧凑跳转列表；加载更早的对话记录后，新的标记才会出现。

## 查看会话概览

会话打开后，Chat 视图右侧的信息卡按“协作”和“运行统计”分组，汇总当前会话的子代理、后台任务数量，以及轮次、步骤、LLM／工具耗时、首 token 延迟、生成速度和 token 用量；卡片不重复显示“会话概览”标题，输入框下方也不显示这些统计。统计来自整个会话；尚未产生样本的项目不会显示。页头原有的子代理和后台任务菜单仍可查看具体条目。Chat 页头右侧的列表形按钮在宽屏默认展开信息卡，侧栏占用空间或窗口变窄时默认收起；点击按钮可切换显示，展开的卡片也可从右上角收起。切换到轨迹等其他视图时，卡片与按钮隐藏，回到 Chat 后恢复先前的展开状态。
