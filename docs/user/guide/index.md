# 使用 Coding 界面

浏览器使用方式请按[根目录 README](../../../README.md#run) 启动 Web UI，命令会打印访问地址；macOS arm64 桌面端由 [Electron 应用](../../../apps/desktop-electron/README.md)提供。本指南从界面已经打开的状态开始。`dsh` 进程会把启动时所在的目录作为默认文件系统位置；全新的界面不会选中任何 Workspace。

macOS 桌面窗口打开时默认最大化，不会进入全屏。双击顶栏空白处可在最大化与还原之间切换；还原后拖动空白处可移动窗口。顶栏按钮和输入框仍可正常操作。

没有保存语言偏好时，界面默认使用中文，不随系统或浏览器语言变化。可在**设置 → 通用设置 → 语言**选择 English；本机连接时选择会保存，后续打开继续使用所选语言。

## 配置模型

没有可用默认模型时，首次欢迎引导会打开提供方与模型配置：选择已有的可用提供方和模型，或添加提供方及至少一个可用模型，再选定默认模型并点击**开始使用**。引导不能跳过；若加载或保存失败，按弹窗提示重试或修复配置。已有可用默认模型时不会显示该引导。之后可在**设置 → 模型**修改提供方与模型，在**设置 → 图片识别**配置纯文本模型处理图片所需的视觉模型；模型变更在下一次请求时生效，无需重启服务器。

**设置 → 通用设置 → 会话标题**决定新会话的标题由谁生成：默认**继承主模型**，标题与对话消耗同一个模型；选**自定义模型**可单独指定一个模型来命名会话，标题请求不再等待对话请求；选**关闭标题生成**则不再调用模型，只用首条消息截出的本地回退标题。该设置只影响此后生成的标题，不改变已有标题与对话模型。

[模型配置指南](./providers.md)介绍其他提供方和自定义 OpenAI 兼容端点。

若某条渠道的网关要求指定请求标识，可在**设置 → 模型**选中该渠道后，在详情**高级设置**里的**模型请求 User-Agent**填写并保存；留空表示跟随产品默认值 `Coding/<构建年>.<月日>.<六位提交哈希> (<操作系统及版本>;<CPU 架构>)`，例如 `Coding/2026.1014.aaaaaa (MacOS 27;arm64)`。它只用于这条渠道后续的模型对话及模型发现请求，不改变已发出的请求，也不影响联网搜索或网页抓取；其他渠道保持自己的值。Free 渠道由应用维护，不提供该输入。远程浏览器或只读设置无法保存。

在已有普通会话的输入框中，收起的入口显示当前模型和推理等级；点击后底部入口显示**选择强度**并打开滑块。拖动时上方档位名称和颜色即时预览，松开后提交当前模型适配器提供的等级，右上角可重置为默认值。点击滑块上方的模型名称可打开并排的渠道与模型列表，左侧选择渠道，右侧按名称或 ID 搜索并选择该渠道的模型；当前模型没有可调等级时会直接打开模型列表。选择从当前会话的下一次模型请求起生效，运行中的请求不变；同时会尝试保存为新会话默认值，保存成功后新会话也采用该选择。输入 `/model` 也可切换模型，切换后采用该模型的默认推理强度。

## 配置联网搜索

`web_search` 默认使用免费的 DuckDuckGo 搜索，不需要 API 密钥。**设置 → 联网搜索**的来源菜单列出九条已装配的来源：免费的 DuckDuckGo、Bing、SearXNG（公共实例自动切换）、AnySearch、Firecrawl、Keenable、Parallel，以及需要密钥的 Tavily（`tavily`）与 DeepSeek（`deepseek-official`）；菜单用「免费」「需要密钥」标出各自代价，该选择只影响联网搜索，不改变对话模型。有匿名额度的免费来源用环境变量提供密钥（`ANYSEARCH_API_KEY`／`FIRECRAWL_API_KEY`／`KEENABLE_API_KEY`／`PARALLEL_API_KEY`），不设置时按其匿名额度运行。选择 Tavily 时，在该页保存独立的 `TAVILY_API_KEY` 凭据；DeepSeek 搜索使用独立的 `DEEPSEEK_SEARCH_API_KEY`，不使用对话模型的 `DEEPSEEK_API_KEY`。所选提供方缺少凭据或搜索失败时会直接报告错误，不自动切换到其他提供方。Bing 可填 `zh-CN` 之类的搜索市场，留空则由 Bing 按 `Accept-Language` 本地化。

每个搜索提供方各自的**出站**在**设置 → 联网搜索**分别配置，互不共享，规则与模型渠道一致：**直连**、**内置代理池**（实际路径由**设置 → 代理池**的池出站决定：池为直连即直连，池为本地池则经池入站，池为自定义代理则经池地址）或**自定义代理**（只影响这一条搜索来源，不受池规则影响）。Tavily 还可修改默认 `https://api.tavily.com` 的 API 基址；DeepSeek 还可修改 Anthropic 兼容 Messages API 的基址，默认 `https://api.deepseek.com/anthropic/v1`。端点、出站和凭据的详细配置见 [DuckDuckGo](../../../packages/web/web-search-duckduckgo/README.md)、[Bing](../../../packages/web/web-search-bing/README.md)、[Tavily](../../../packages/web/web-search-tavily/README.md)和 [DeepSeek](../../../packages/web/web-search-deepseek/README.md) 搜索提供方。

## 选择主题外观

**设置 → 主题外观**是换肤的地方。上半部分是按来源分组的配色墙：内置的浅色、深色与跟随系统，加上随应用提供的 47 套配色——幻梦 8 套、轴伊 2 套、OpenCode 调色板 37 套。卡片优先显示该主题的界面截图（幻梦与轴伊带截图，跟随明暗的轴伊会随当前明暗换图），没有截图的主题显示它的底色、强调色与正文色。点任意一张卡片立即生效，卡片下方可以收藏，也可以按来源或收藏筛选、按名称搜索；卡片墙自己滚动，不会把下面的高级外观推得很远。「随机换一个」挑一套没在用的，「还原默认」回到跟随系统。来源、移植内容与未移植的能力见[主题来源说明](../../../packages/client/ui-theme/NOTICE.md)。

「高级外观」四块都叠加在当前配色之上，不改动配色本身：

- **壁纸**：默认使用主题自带的弥散光。可改为关闭、六个渐变预设之一，或自己的图片（粘贴图片地址，或选择本地文件——图片会先压缩到最长边 2400px，仍超过 2 MB 时提示换一张）。可见度越低，画布越实；模糊作用于壁纸本身；图片还能选裁剪填满、完整显示或平铺。
- **强调色**：12 个常用色块或自定义颜色，覆盖按钮、选中态与焦点；选「跟随主题」撤销。
- **玻璃与不透明度**：磨砂材质会给遮罩加背景模糊并把壁纸再柔化一点；降低面板不透明度让菜单、弹层与卡片透出背后内容。
- **主题包**：把当前配色与外观导出成 `*.theme.json` 分享，或导入别人的主题包；「复制分享链接」生成带 `#theme-pack=` 的地址，对方打开即导入。

选择与外观都写在用户设置里，重启后仍是同一套；**设置 → 常规**里的「外观」行照旧只切换浅色／深色／跟随系统，选择主题预设时它会点亮当前生效的明暗。远程连接模式的浏览器没有特权设置通道，那里的改动只在当前进程有效。

## 选择开始方式

点击**选择工作区**即可搜索已列出的 Workspace。若要在本地项目中工作，可选择已有 Workspace，或选择**打开文件夹**并选取项目目录。Session 打开后，编辑器即可使用。

选择**不在项目中工作**会在 Host 用户 HOME 目录创建 Session，但不会注册 Workspace。只有没有当前 Session 时，编辑器才不可用。

新对话欢迎页右上角有两个面板按钮：左侧打开或收起横跨主内容的终端底栏，右侧打开或收起整个右侧边栏。进入具体对话后，两个开关仍在对话页头右上角；工作台顶栏可关闭工作台，接管对话区时还可从顶栏切换终端底栏。页头和欢迎页的右侧按钮提示为“打开右侧边栏”或“收起右侧边栏”，再次点击会收起整个右栏；关闭右栏不会收起已打开的终端底栏。右侧按钮不控制左侧导航栏；通过欢迎页按钮打开一个面板时会收起另一个，再次点击则关闭该面板，不折叠导航栏。工作台中的普通面板开关可以同时显示两个面板。

打开工作台后，功能菜单提供**变更记录、终端、文件**和已装配插件的入口。选择**变更记录**会在右侧打开只读 Git 提交树；选择**终端**会在右侧新建终端标签；选择**文件**会创建或切回该会话唯一的文件管理器标签，点击树中的文件则打开文件预览。选择**Agent 浏览器**打开该会话的浏览器视图，尚无页面时显示空状态，不会自行创建网页；有页面时每个浏览器页面占一个工作台顶栏标签，选中即可查看该页，不另设内部页面标签。工作台顶栏的共享 `+` 显示功能菜单，本身不创建页面或终端；右侧终端与底栏终端可独立使用。

已装配的 Client 插件也可在同一个 `+` 菜单增加入口，并在所属 Session 的右侧工作台打开自己的标签；没有此类插件时菜单仅显示上述内置功能。外部标签仍使用单个右侧面板，不提供分栏或浮动窗。

Agent 浏览器的页面视图与 Git 历史、文件、终端和其他插件标签共用工作台顶栏。关闭某个浏览器视图只移除工作台标签，不会关闭浏览器中的网页；若要结束页面，可让 Agent 使用浏览器标签关闭工具。

工作台较窄时，文件预览标签独占内容区，不显示文件树；切回文件管理器标签，或从功能菜单选择**文件**，即可继续浏览目录。较宽时文件管理器和文件预览均显示文件树。

终端底栏的 `+` 可新建独立终端，点击标签切换；标签上的关闭按钮结束该终端。亮色或暗色主题下，鼠标圈选终端文字都会用与终端相反的明暗色绘制选区，失焦后仍可辨认文字。Shell 执行 `exit`（或当前 Shell 支持的 `quit`）并断开连接后，对应标签会自动关闭；意外断连仍可在原标签重连。最后一个标签关闭时底栏收起，再次打开会创建新终端。底栏右侧的关闭按钮只收起底栏，重新打开时仍可使用未关闭的终端。

切换右侧标签、切换对话或收起右栏与底栏时，已打开终端的进程和输出会保留。关闭终端标签会结束对应终端；关闭右侧的最后一个标签回到功能菜单，底栏继续按自己的状态显示。终端连接断开、移除对话或关闭应用后，原进程不会继续保留。

已有空白 Session 时，面板按钮会沿用该 Session；还没有当前 Session 时会先连接最近使用的 Workspace，没有 Workspace 则在 Host 用户 HOME 创建未分组 Session。发送第一条消息后，所选面板会在这次对话中保持打开。

在 Coding 桌面端中，选择**远程连接**，先选连接模式，再输入 SSH 主机、使用密码或私钥认证、确认未知主机密钥并选择远程目录。默认的**基础模式**只使用 SSH（在 POSIX 远端另复用一条常驻 Shell 列举目录、规范化路径），无需上传远端 agent 或允许 SSH TCP 转发；文件内容仍经 SFTP 读写。它支持远端目录浏览、文件读取／写入／编辑、`glob`／`grep` 搜索、前台与后台 Bash 命令、持久终端／PTY，以及 Code Mode 的 Bash 和远程文件工具。基础模式不支持 LSP；Windows 远端不支持基础模式的命令与 PTY 操作，执行请求会明确失败。

基础模式写入使用 SFTP：原子创建需要服务器支持 hardlink 扩展，覆写与编辑需要 `posix-rename@openssh.com`，缺少相应扩展会失败。按版本覆写会在提交前复核文件，但 SFTP 不提供原子的版本比较交换，并发写入仍可能发生在复核和发布之间。SSH 不提供前台进程组查询，终端的相应检查不可用；信号或终止请求不能保证远端进程树已经退出，状态不明时会报告失败，请检查远端状态后再操作。

需要 LSP 或 Go agent 提供的远端执行语义时，选择 **Agent 模式**。它也支持文件读写编辑、搜索、前后台 Bash、持久终端／PTY 与 Code Mode，会部署仅监听远端回环地址的小型 Go agent，并需要 SSH `direct-tcpip` 转发；目标侧不需要 Node。两种模式的 Code Mode 都经 esbuild 转换 TypeScript 并在隔离的 Goja 中运行，拥有声明的工具 binding，但没有 Node 内建模块、`process`、`require` 或 Host 环境；基础模式的 Goja 隔离进程在桌面 helper 本机，文件与 Bash binding 仍指向远端，不会回退到本机工作区或 Node worker。

勾选「记住此连接」时，密码或私钥加密保存在 `$DSH_HOME/ssh_config.yaml`（主密钥在 `$DSH_HOME/remote-ssh/master.key`，权限 0600），不勾选则只保留在当前对话框／连接中；未知主机密钥需要明确确认，已变更的主机密钥会使连接失败。保存过档案的远程工作区在应用重启后再次打开时会自动重连，无需重走向导；没有可用档案时需要重新连接。远端工作区在选择菜单和侧边栏用云朵图标与本地目录区分；远端文件工具可以读写整台远端主机上的路径，`../x` 指向远端父目录，最终权限由 SSH 账户决定，而**工作区写入**模式仍只允许改动所选目录内的文件；普通浏览器界面不能发起 SSH 连接。本地 Host 仍负责工具审批和持久 Session 日志。远程 Bash 需要使用**完全访问**（`danger-full-access`）；这不是远端沙箱。连接断开、marker 过期或所选模式不支持操作时，请重新连接或选择合适模式；操作会失败，不会改在本机运行。基础模式的连接断开会被立即识别，随后的操作直接失败并要求重新连接，不会长时间等待。

## 运行任务

启动一个会话并发送：

> Summarize this repository and identify its main packages.

Agent（智能体）可以读取和编辑工作区文件、运行命令、委派工作并维护计划。如果根据当前权限策略，某项操作需要审批，Web UI 会先询问你。

创建新项目时，Agent 会在实现业务代码前，先在项目根准备 `README.md`（目标、核心功能与可用的启动／使用方式）、`AGENTS.md`（结构、技术栈、实际命令、规范与安全边界）和从 `AGENTS.md` 链接的 `docs/codemap/README.md`（按任务定位模块、入口、职责与连带验证；模块增多时再补子图）。已有地图会沿用原路径。进入项目后先读地图总入口及相关模块、专项文档，再核对源码；架构或数据流变化时，代码验证后同步地图与必要的流程图。这些文件应在仓库独立检出后仍可用：内部引用使用相对链接，不依赖本机绝对路径、仓库外的其他项目或 Coding 的会话记忆；依赖和安装前提应写清，尚不可用的命令如实标注。已有文件会先读后增补。

在项目中工作时，Agent 默认先检查 Git：复用已有仓库（包括父级仓库或 worktree），尚未初始化时才在项目根创建本地仓库，并先保存安全的项目基线，便于首次回滚。之后每完成一个独立、可检查和回滚的步骤，验证通过就创建本地提交，不等到任务收尾；只包含该步改动，排除你的无关改动、凭据等敏感内容及构建产物。你可以明确要求“不要提交”；Agent 不会自动推送到远端。这些是对 Agent 的默认指导，不是打开项目时由应用自动执行的操作。

Agent 使用 `ask_user_question` 询问选择或缺失信息时，可在对话中回答；从工具开始等待起五分钟仍未收到回答，待回答问题会撤回，模型收到“用户未响应 需要自行决策”，继续依据已有信息判断。超时不会替你选中某个选项；需要权限的操作仍遵循原有审批策略。

某一轮请求失败时，对话里会留下一条“本轮运行失败”行并给出原因；行上的**重试**按钮会回到开启这一轮的那条用户消息重新发送一次（文本原样，图片重新提交），不改写也不复用已有记录，因此失败行与新的发送都会保留。Host 接纳前按钮保持禁用，连点不会重复发送；仍被拒绝时原因显示在输入区。

图片可以粘贴或拖入输入区，支持 PNG、JPEG、WebP 和 GIF。草稿保留原始文件；发送时 Host 对过大但仍处于源安全额度内的图片统一缩小／压缩，不能在保留动画语义的前提下达到最终限额时会提示失败，不会把动图悄悄变成静态图片。单次最多 20 张；默认源图片单张及消息总额各为 100 MiB，最终单张上限为 3.5 MiB、单边为 2000px。

### 让 Agent 使用浏览器

在本地会话中提出网页任务，例如“打开这个网页，读取标题并检查页面”。本机需已安装 Edge、Chrome 或 Chromium；桌面、Web 和 CLI 的默认 Agent 浏览器均使用本机浏览器。Agent 按需加载 [`browser-use` 技能](../../../packages/skill/skill-browser-use/README.md)，再通过 `browser_navigate` 打开网页、`browser_snapshot` 读取页面语义内容、`browser_click`／`browser_fill` 操作页面；还可读取页面信息、列出本会话标签、滚动、等待页面变化、按键、读取单个控件、选择表单项或检测人机验证，工具名称统一以 `browser_` 开头，共 35 个：除常用导航与交互外，还包含标签打开/切换/关闭、上传与下载、等待网络响应、网页对话框、页面脚本、CLI、登录态导入、空间管理与环境诊断。页面快照的元素引用可用于操作，也可使用 CSS 选择器；每次动作应根据返回状态重新观察。高风险工具仍按会话权限逐次审批。普通页面文本不等于视觉验收，Agent 需要用 `browser_screenshot` 取得真实图片后才可判断外观；看不到图像时应说明未能目视验证。

打开右侧工作台选择**Agent 浏览器**，可观察本会话的网页；浏览器工具首次活动也会尝试打开该会话的工作台视图。浏览器默认无独立窗口，不抢前台。每个页面对应一个工作台顶栏标签，点击切换画面，关闭标签只关闭视图，页面继续运行且可由 Agent 操作。页面上方的地址栏可输入 HTTP(S) 地址，按回车或点击**打开网址**提交；失焦不会清除未提交的网址，省略协议时自动补 `https://`。相邻按钮可后退、前进和刷新网页，不是刷新页面列表。页面画面内可点击和滚动，点击网页输入框后直接用键盘输入文字或使用回车、退格、方向键等常用按键；无需底部文字栏。浏览器内容区没有第二层标签或历史动作抽屉。需要登录扫码或人机验证时，可点**在浏览器窗口中打开**，把无窗口的浏览器切换到可见窗口；人机验证提示会出现在画面上方。视频后端不可用时画面回退为单帧。

页面列表加载失败时可点击画面中的**刷新页面列表**按钮重试；暂时没有画面时，不会把空白画面当作网页内容，禁用画面转发时会提示到设置中开启。人工导航或输入失败时先重新观察页面，不要把旧画面当作操作已完成；面板不会把操作结果自动提供给模型。

工作台不提供“点击聊天链接即在面板新建页面”的功能。要让 Agent 使用对话里的地址，请明确要求其打开该链接；若只想自行浏览，可用自己安装的浏览器打开。

画面上的点击与滚动只投递给当前展示的网页；键盘文字从页面焦点处插入，不替换整个输入框，常用导航键可操作当前输入控件，但组合快捷键和任意网页脚本不属于人工面板。错误时重新观察页面再试；远程 SSH 工作区不提供本机 Agent 浏览器工具。

工作台画面是当前会话页面的独立画面流，不是页面 DOM，也不是 Agent 截图附件；切换标签、关闭浏览器视图或收起工作台只停止该视图的预览，不停止 Host 页面。若需让模型按画面判断外观，请让 Agent 显式调用 `browser_screenshot`，并在允许保存文件的会话中检查结果。

浏览器设置位于**设置 → 插件 → Agent 浏览器**：可选择采集后端（自动、CDP 单帧、视频）、画面质量与帧率、FFmpeg 路径与编码器、固定视口、无窗口运行、页面光标标签、浏览器程序路径、空闲回收与常驻执行器等。视频后端需要本机 FFmpeg；视频不可用或播放失败时回退为单帧画面。视频画面和单帧画面均可点击、滚动，并在聚焦画面后输入文字和受限的常用按键。部分运行方式设置在下一次浏览器启动时生效。

模型浏览器工具仍受当前会话权限约束：**完全访问**且关闭审批提示时普通操作可直接执行，其余组合需逐次获批；拒绝或取消后工具调用不会执行。人工工作台通过本机同源 Host 路由操作，Host 仍检查会话、页面归属及输入边界，不能通过前端界面越权操作其他会话的页面。`browser_screenshot` 会向工作区写入新文件，只读会话不可用；页面跳转或动作失败后，先重新观察页面，不要假定旧元素引用有效，也不要自动重试提交。登录、双重验证或人机验证需要可见窗口时，点页面上方的**在浏览器窗口中打开**，完成后再让 Agent 继续。

浏览器工具只支持本地会话；远程 SSH 工作区请求会失败，不会改用本机浏览器。`browser_navigate` 只接受明确的无凭据 HTTP(S) 绝对地址，不接受 `file:///` 地址或粘贴的 Markdown 链接；该限制不是网站目的地白名单，页面跳转或加载子资源时仍可访问其他来源。页面控件、登录框及网络内容都可能包含不可信信息，谨慎确认对外发送与下载。工具的具体参数与安全边界见[浏览器技能](../../../packages/skill/skill-browser-use/README.md)。

### 让 Agent 操作本机应用

在本地 macOS Session 中提出本机应用任务，例如“打开备忘录，新建一条并写上今天的待办”。这一能力需要 Agent 先加载随预设提供的 `dsh-computer-use` 技能，加载后会看到 `computer_list_apps`、`computer_observe`、`computer_click`、`computer_type_text`、`computer_press_key`、`computer_scroll`、`computer_drag`、`computer_set_value`、`computer_perform_action`、`computer_wait` 与 `computer_confirm`；标准模式的原生调用与 Code Mode 程序提供的工具名相同，未加载技能时只有一个说明如何加载的引导工具。整个能力只在本地 macOS 宿主上装配，其他平台不注册任何工具或技能。

Agent 先列出运行中的应用，再对选定应用取一份观察：有界可访问性树、当时的元素表，需要时加一张截图；随后按元素或坐标执行动作，每次成功动作都会返回动作之后的新观察，元素消失或观察过期会明确失败而不会点到别处。观察与输入都需要 macOS 的辅助功能权限，只有截图需要屏幕录制权限；请在**系统设置 → 隐私与安全性**里把这两项授予运行 Coding 的程序，未授权时工具会给出可操作的错误，不会带权限缺口继续操作。

权限规则与浏览器工具一致：当前会话使用**完全访问**（有效沙箱模式为 `danger-full-access`，有效审批策略为 `never`）时操作无需逐次审批，其他组合按会话权限逐次询问，拒绝后本会话内不再重试同一应用。对外发送、不可逆删除、改动账户与安全设置、完成支付等高影响动作还要求一次性确认；审批提示被禁用时这些动作不会执行。按应用的静态授权写在[配置目录](../../config-catalog.md)里（`computer-use` 的 `grants`，或 `allowAllApps`），未配置的应用走审批。

截图作为产物写入当前会话工作区，输入只投递给选定进程：不会移动你的真实光标，也不会因为你正在使用的应用而抢占前台；屏幕上另有一个独立光标提示 Agent 的动作落点。这个能力不是实时画面，也不提供暂停或人工接管：需要停止时直接停止当前任务。能完成同一件事的专用 CLI、API 或[浏览器工具](#让-agent-使用浏览器)始终优先于本机界面操作，详细契约与限制见[电脑控制包](../../../packages/computer-use/computer-use/README.md)与[工具包](../../../packages/computer-use/tool-computer-use/README.md)。

Chat 视图左侧的细轨标出已加载的用户消息和中途引导消息，阅读时会突出当前位置；悬停或键盘聚焦可预览消息，点击或键盘激活可跳回对应位置。较窄的窗口改用紧凑跳转列表；加载更早的对话记录后，新的标记才会出现。

## 逆向分析模式

在会话的模式选择里选**逆向分析模式**后，该会话获得 [REA（Reverse Engineer Anything）](https://github.com/morluto/rea) 的 `mcp__rea__*` 工具，以及随模式分发的逆向调查技能；其它模式不注册这些工具。还没产生对话的空白会话可以直接切换模式，已经开始的会话保留它启动时的模式，需要换模式时新建会话。

工具覆盖原生二进制的反汇编与反编译、安装包与归档清单、固件区域拆解、JavaScript／Electron 应用、Android 包、版本对比、崩溃记录与运行时观测；实际可用项取决于本机装好的分析引擎，Agent 会先按目标类型选工具，缺引擎时说明缺什么。技能目录里的 `reverse-engineering` 给授权边界、调查计划与证据台账，`rea-tool-workflow` 给工具路由与恢复路径，其余技能按目标类型分别讲原生二进制、JavaScript／Electron、Android、固件、内核驱动、漏洞研究、保护措施、行为克隆、游戏与版本对比；正文按需加载，也可以在消息里写 `/reverse-engineering` 这类命令显式调用。

前提与排错：

- 本机需要 Node.js 与 npm，且版本满足 REA 的要求（Node 22.23.4+、24.22.1+ 或 26.12.1+）。版本不符时 REA 报告版本要求，应用不会自行升级 Node。
- 首次切入该模式时 `npx` 会下载固定版本的 `rea-agents` 包，需要联网；下载期间新会话的创建会等待，之后复用缓存。
- 原生分析使用本机已安装的 Hopper、Ghidra 或 IDA，Android 分析使用自备的 JADX 与 Java，固件拆解需要 Binwalk 或 Unblob，抓包分析需要 Tshark，纯静态的 JavaScript／Electron 分析不需要引擎。缺失时只有依赖它的调用失败，其余工具照常可用。
- 需要诊断时让 Agent 在终端运行 `npx -y rea-agents@latest doctor --json`；它只读，不改配置。

这个模式的系统提示词按分析任务单独编写，不是标准模式的替身。它把通用编码约定里的「小步改动、每步提交」理解为「让每一步都能撤回」，并把这条目的接到分析会话上：目标产物只读、分析前先记文件哈希与版本、只在副本上操作；分析目录若还不在任何 Git 工作区内，它会先 `git init`、检查 `.gitignore` 并为已有文件建一次基线提交，用忽略规则把目标副本与大型证据挡在版本库外，让笔记、复现脚本与小型证据都能逐步撤回；运行目标程序、附加调试器、hook 与系统改动没有提交这种回退手段，因此要先说明会改变什么、怎么恢复、结束时清理什么，你没要求运行时验证时只做静态分析。只有你要求实现或修复时，它才回到常规编码节奏（小步改动、每步验证并本地提交）。提示词同时要求先列问题清单与证据台账（结论、证据位置、证据类型、置信度、搜索边界、未知项），大目标先取摘要再分页，重复失败或超大调用不重放，调查结束时关闭打开的原生会话并把证据导出到项目里。

分析对象必须是你自己拥有、或你明确获授权测试的软件。技能要求把已确认的事实、推断与未知分开写，并为每条结论给出函数、地址、文件或抓包记录作为证据；发现漏洞时报告影响与复现证据，不产出武器化载荷，分析保护措施时只做识别与评估。这个模式里的文件读写、Shell 与浏览器工具仍按当前会话的权限预设与审批规则工作。来源归属见[模式来源说明](../../../apps/cli/config/agent-presets/reverse/NOTICE.md)。

## 长线任务模式

在会话的模式选择里选**长线任务模式**后，主 Agent 不再自己从头做到尾，而是把任务拆成阶段，再按阶段并行推进；它具备标准模式的全部编码工具，另外多一个等待子代理的工具。和切换其它模式一样，空白会话可以直接切，已经开始的会话保留它启动时的模式。

它的工作顺序是固定的：

- 主 Agent 先把任务拆成阶段，每个阶段拆成互不依赖的目标，写清范围、验收标准和要跑的验证，并在同一个消息里把这些目标一起派给多个子代理并行执行。
- 派完就进入等待：主 Agent 阻塞等子代理的投递（回报或结束通知），而不是反复查询状态，也不趁等待自己去做子代理的目标。
- 一个阶段的目标全部结束后，主 Agent 派一个独立的验收代理核对 diff、提交与验证结果。验收代理只读：不改文件、不提交、不替执行者补缺。
- 验收未通过时，缺口清单发回原来的执行者继续修，修完重新验收；通过才进入下一个阶段。

每个可回滚的步骤仍由执行者自己跑验证并本地提交，提交里只含该步相关文件；验收会核对该提交没有夹带别的目标或无关文件。上下文交接（子代理、压缩、跨会话）只保留主线目标、阶段表与每个目标的验收状态，探索路径、中间输出和失败尝试留在各自子代理的记录里，需要时再按 id 取。委派只有一层：执行者不会再往下派子代理，因此等待链是平的，验收也只由主 Agent 发起。

## 查看会话概览

会话打开后，Chat 视图右侧的信息卡按“协作”和“运行统计”分组，汇总当前会话的子代理、后台任务数量，以及轮次、步骤、LLM／工具耗时、首 token 延迟、生成速度和 token 用量；卡片不重复显示“会话概览”标题，输入框下方也不显示这些统计。统计来自整个会话；尚未产生样本的项目不会显示。页头原有的子代理和后台任务菜单仍可查看具体条目。Chat 页头右侧的列表形按钮在宽屏默认展开信息卡，侧栏占用空间或窗口变窄时默认收起；点击按钮可切换显示，展开的卡片也可从右上角收起。切换到轨迹等其他视图时，卡片与按钮隐藏，回到 Chat 后恢复先前的展开状态。

信息卡中的 Git 区域按当前会话目录显示仓库状态，非仓库不显示。“Git 变更”行展开后可切换本地分支、查看变更与同步状态，并用“推送”“拉取”操作当前上游：推送会先暂存该仓库全部未忽略的改动并生成提交，再推送到当前分支的上游；拉取只接受快进，分支分叉或本地文件阻挡时提示新建会话解决冲突。远端要求认证时，客户端先尝试系统 Git 凭据助手和这台机器上已保存的凭据，两者都不可用才弹出对话框要求输入账户名与密码或访问令牌。勾选对话框里的“记住这组凭据，下次自动使用”会在推送或拉取成功后把这组凭据保存到本机凭据存储（`$DSH_HOME/.credentials.yaml`），此后自动使用；被远端拒绝时可在这个对话框里清除它并重新输入。Git 操作仅在本机回环客户端可用，远端工作区不会回退到本机仓库。
