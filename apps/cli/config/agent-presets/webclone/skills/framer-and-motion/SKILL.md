# Framer 与动效页面

Framer 生成的页面，或动静效超出简单悬停过渡的站点用这份方法。Framer 只是发布工具；要复现的是它渲染出来的设计与行为，目标框架由本项目决定。

## Framer 页面的检查

Framer 会同时渲染桌面与移动两套节点，用断点 class 隐藏其中一套。按视口分别读**可见**的布局与计算样式，不要把两套节点一起抄下来。`data-framer-name` 能定位区块；自动生成的 class 不等于组件结构。

等水合与入场动画结束，再把首屏以下的内容滚一遍。位移重要时同时留初始与揭示后的位置。整页截图可能把尚未揭示的屏外内容截成空白。

取图用 `currentSrc`、分辨率要够最大渲染尺寸、裁切按实际观测。Framer CDN 的图片 URL 可能返回 AVIF 而扩展名仍是 PNG：核对字节并本地用真实格式。字体与 SVG 定义也是保真的一部分。

声明 `@font-face` 之前先确认每个字体的真实字重与字形；把只提供某个字重的静态文件当作可变字体，会让正文整体偏粗。资产打包取不到的公共字体，直接下载观测到的 URL。导出的内联 SVG 要带上命名空间与它引用的定义才能在独立文件里工作；用本地 `<img>` URL 验证一次渲染，不只看内联效果。

动态 SVG 可能依赖祖先选择器、共享符号、字体与样式表关键帧。保留这些依赖，并观察完整一轮周期：把循环序列换成几个一起脉动的对象，源站行为就丢了。

CMS 网格要把给出的路由都走一遍，逐个操作筛选。目标是可用的跳转与筛选，而不是一张静态首屏列表。

用语义化的组件与数据重建。部署脚本与压缩包装是证据，不是可以直接粘进新工程的代码。

## 动效检查

| 驱动 | 证据 | 常见实现 |
|---|---|---|
| 时间 | 周期、暂停、方向、循环媒体 | CSS 关键帧、视频、动画库 |
| 滚动揭示 | 进入边界、起止位置、反向是否重播 | IntersectionObserver + CSS |
| 连续滚动 | 进度、固定时长、各层速度 | 滚动进度 + CSS 变量或动画库 |
| 点击／悬停 | 替代内容、过渡、关闭或跳转 | 组件状态 + CSS |
| 指针／画布 | 响应方式、渲染器与媒体身份 | 匹配的渲染器，或明确说明的近似方案 |

正反两个方向与移动端都要看。粘性场景需要记录滚动距离与释放行为，只写 `position: sticky` 不够。看着像动效的画面可能就是视频：有真实媒体就用真实媒体。

可量测的缓动与时长要匹配上。动画循环跟随组件生命周期清理。Framer 的平滑滚动是 Lenis：`html` 上的 `lenis` class 或全局的 `window.lenis` 会把选项暴露出来，照着复现。

## 验证体验

在可比位置上比较初始、进行中与稳定三态。动效进行中操作控件，再离开并返回，看是否卡住。确认动效不会撑宽文档，也不会永久遮住内容。没实现的着色器或画布行为要说清名字，不能拿一张静帧当证据。

用 `browser_script` 在**一次调用里**设视口、驱动输入并截图，避免拆分调用后状态丢失；判定画面必须看 `browser_screenshot` 或 `page.screenshot` 的图。
