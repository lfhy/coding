# 思维导图编辑器

`coding-client-ui-mindmap` 在笔记正文显示可滚动的分支画布。选择节点后可添加子节点、编辑文字、移动分支到其他上级、调整同级顺序或删除分支。主节点只能编辑或添加子节点。方向键在画布内移动焦点和选中项，Shift+Tab 返回工具栏；删除分支前需要确认。

## 装配与保存

本包没有配置项。它与[笔记页](../ui-notes/README.md)并排挂载，通过 `ctx.slots.inject` 等待会话范围内的 `notes.document.mindmap` 声明；笔记页提供相对于笔记根目录的 `path` 与当前显隐 `shown`。声明撤销时编辑器贡献随之移除。编辑器只消费[文件库](../../attachment/file-library/README.md)提供的同源导图读取与编辑接口，不依赖文件库的运行时模块。

每项确认将相同路径和已读取版本与一个结构操作一同交给 Host 保存，不在工作区生成第二份文件。可见时约每四秒重新读取，包括助手写入的改动；背景读取只替换已保存的画布，不更改弹窗中的输入。有写入进行时不会应用较早的读取结果，切换路径或隐藏后也不会接纳旧实例的响应。

版本冲突时，编辑器保留当前输入并要求在弹窗中明确刷新。刷新成功后，用户可以检查新画布并再次提交；源节点或移动目标不再可用时不能继续提交该操作。文件被删除或移走后不再显示旧画布；其他加载与保存失败提供重试提示，不显示宿主诊断。

## 验证

运行 `pnpm exec vitest run packages/client/ui-mindmap/tests` 检查贡献释放、节点操作、冲突、轮询和路径切换。部署和浏览器端验证从实际客户端组合打开笔记页。

## Model Experience

无直接影响：本包只编辑浏览器中打开的笔记，并不向模型请求添加内容或工具。

#### KV Cache effect

无；本包不组装或发送模型请求。

## Known Limitations and Deferred Work

通过工具栏移动、调整顺序，不支持在画布上拖动分支。取消弹窗或离开当前导图会放弃尚未提交的弹窗输入。
