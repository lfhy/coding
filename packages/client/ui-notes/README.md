# coding-client-ui-notes

笔记界面：外侧窄导航的「笔记」入口、独立主内容页，以及完全复用对话的 AI 助手栏。

## 页面结构

笔记占用 `shell.page` 的 `notes` 键。页内目录复用 `SidebarRoot`，与对话侧栏共用宽度和折叠状态；目录行独立滚动，加号与「全部笔记」标题同行，收起时仍留在图标轨顶部。中央顶栏展示已打开文档的横向可滚动标签，目录项负责打开或选中标签，标签可切换或关闭。下方 `NotesDocument` 承载活动文档，头部提供标题和助手入口；共享页头的保存状态与导出菜单只用于 Markdown。Markdown 正文在「编辑／并排／预览」之间切换，中央实际宽度至少 640px 时默认并排；不足时隐藏「并排」，默认编辑，仍可切换到预览。视图切换不丢弃草稿。并排时源码与预览互相带动滚动：按两侧可滚动余量等比换算，滚到底两侧同时到底；单栏视图不联动。

幻灯片（`.codingppt` 工程目录）通过 `notes.document.ppt` 复用 PPT 工作台；思维导图（`.codingmindmap` 文件）通过会话范围内的 `notes.document.mindmap` 挂载[导图编辑器](../ui-mindmap/README.md)。Word（`.codingword`）与 Excel（`.codingexcel`）通过会话范围内的 `notes.document.office` 挂载 [ui-office](../ui-office/src/client/index.ts) 的开源 Univer 编辑器。笔记页传入相对笔记根目录的 `path` 和显隐状态 `shown`，Word 与 Excel 还传入 `kind`。结构化文档共用目录和标签操作，不进入 Markdown 草稿流程。

未选中笔记时，正文显示插画、随本地时间变化的问候和一句说明，不重复显示新建入口。宽窗口默认并排打开右侧 AI 助手；窄窗口默认收起，可从页头打开抽屉。助手复用相同会话的对话，收起或改用抽屉不另建会话。并排呈现时助手与正文之间有一条可拖拽的分隔条，宽度偏好保存在根布局 store（默认 400px，范围 400–760px），正文至少保留 648px；空间不够时不动偏好，改用抽屉。助手页头的「新对话」按钮在同一笔记目录上新建会话，仍切到「笔记专用模式」，页面与助手保持在原位；新会话完成前重复点击被忽略，失败时保留当前对话与草稿。

页面通过 `shell.page` 的 store 记住活动文档路径、已打开标签顺序与展开的目录；不在该 store 中持久化正文草稿。切回笔记页或重新载入窗口后恢复标签并重新读取正文。目录首次加载时移除已不存在的标签，页面删除、重命名或移动文件／目录时同步其标签；关闭活动标签会选中相邻标签，最后一页关闭后回到欢迎区。切换或关闭 Markdown 标签先保存当前草稿，保存冲突或失败时留在原页并保留未保存改动。离开页面会触发 Markdown 草稿保存。新建会话从欢迎页开始，不继承上一个会话的浏览位置。

## 目录操作

「全部笔记」标题旁的加号菜单有「新建」和「导入」两项。「新建」项带箭头，可悬停、点击或聚焦后按右方向键展开，依次显示「目录」「笔记」「幻灯片」「思维导图」「Word 文档」「Excel 表格」。子菜单优先向右展开，右侧空间不足时改向另一侧。选择「新建」的子项会打开对应的创建弹窗，默认保存到「全部笔记」。新建幻灯片生成 `{名称}.codingppt` 工程目录和默认整稿；新建思维导图复用名称和「保存到」表单，由文件库生成只有中心主题的 `{名称}.codingmindmap`。新建 Word 或 Excel 也使用该表单，由 Host 创建空白原生文档。

「导入」展开「文本」「幻灯片」「思维导图」「Word 文档」「Excel 表格」，各有独立的文件选择器、扩展名白名单和失败提示。**文本**接受 `.md`／`.markdown`／`.txt`（不超过 1 MiB，按 UTF-8 解码）并写成带原文的笔记。**幻灯片**只接受 `.pptx`，由 Host 解析后写进同样的工程目录（不按演示文稿大小设限，只按解包预算拦截畸形文件）。幻灯片目录树条目以展示框图标与普通目录区分，点开即挂载工作台。

**思维导图**接受原生 `.codingmindmap`（不超过 1 MiB）或含根级 `content.json` 的现代 XMind ZIP（`.xmind`，不超过 16 MiB）。XMind 只导入首张图的主题文字、层级和顺序，不带入样式、附件或其他图页。两种格式均在笔记根目录保存一份原生文件，不改源文件；无效或超限的导入不留下半成品，同名文件不会被覆盖。导图在菜单、目录和标签中使用 `file-mindmap` 图标。

**Word 与 Excel** 分别导入 `.docx` 与 `.xlsx`；Host 在本地转换并另存为笔记根目录下的原生文件，不改源文件。保留范围见[用户指南](../../../docs/user/guide/index.md#笔记)，导入限额见[文件库说明](../../../docs/subsystems/attachment.md#word-与-excel-文档快照)。

目录行的行内按钮和右键菜单只提供新建笔记和新建子目录两种创建操作，打开弹窗时默认保存到该目录。「保存到」菜单把子目录逐级缩进，选择后显示完整位置；每一行（包括「全部笔记」）都有独立的「新建子目录」图标按钮，点击后在同一弹窗切换到以该行为父目录的目录表单。取消目录表单会返回原创建表单，保留名称和保存位置；创建成功后刷新目录树、选中新目录，并带着原名称返回原表单。目录刷新和正在编辑的笔记不会改变选中的位置。创建成功后展开父目录，让新条目可见。

侧栏展开时，行末默认显示修改日期；鼠标悬停或键盘焦点位于行内时，[`SidebarRootItem`](../ui-primitives/README.md) 在日期位置显示重命名和删除按钮，目录行同时显示新建笔记和新建目录按钮。右键菜单提供同样的操作。侧栏收起时隐藏行内按钮，标题加号仍可用。

目录树支持原生拖拽：文件、普通目录和 `.codingppt` 幻灯片工程都可拖动。拖到普通目录行中部会移入该目录，拖到任意条目的上、下边缘会在目标同级位置插入；落点无效时不接受放置。搜索或创建期间禁用拖拽，目录不能移入自身或后代。移动前先保存活动 Markdown 草稿，保存失败则不移动。

思维导图、Word 和 Excel 重命名保留各自的原生后缀，不改变内容。行内按钮和右键菜单发起的删除都不可撤销，须在弹窗中确认；取消不会发出删除请求。Markdown、思维导图、Word 和 Excel 按单文件删除，真实目录连同其文件和子目录递归删除。失败时可在同一弹窗重试；成功后立即更新目录树。删除路径仅限笔记根目录内，且不跟随条目符号链接。

## 数据源

目录树、Markdown 原文读写、目录操作来自[文件库](../../attachment/file-library/README.md)持有的笔记域（`~/.coding/files/notes`）。幻灯片的 `.codingppt` 工程目录由文件库独占创建，工程文件（`deck.json`、`history.json`、`media/`、导出产物）由 PPT 宿主直接写在该目录里，不保存单文件 `.pptx` 源稿，也不另建 `ppt/` 会话工程目录。新建走 `/api/ppt/notes/create`，导入走 `/api/ppt/notes/import`，页面随后按工程目录挂载工作台。页面只消费 HTTP 接口，不直接读写文件系统。

目录移动与排序统一调用 `POST /api/notes/move`，请求为 `{path,directory,before?}`：`directory: ''` 表示根目录，`before` 为目标目录直属条目路径，`null` 或省略表示末尾，成功返回移动后的 `{path}`。同目录只调整持久顺序，跨目录保留名称且不覆盖同名条目。客户端成功后同步打开的标签、活动草稿路径、展开目录和写入检测路径，再刷新目录；请求失败时先刷新 Host 最新目录，避免界面保留已经移动的旧路径。

思维导图使用文件库的同源接口：笔记页调用 `POST /api/notes/mindmap/create` 和 `POST /api/notes/mindmap/import`，编辑器调用 `GET /api/notes/mindmap/read` 和 `POST /api/notes/mindmap/edit`。结构化写入与笔记目录创建、移动、改名和删除共用文件库写入队列；编辑按读取到的 `revision` 成批提交，版本冲突返回 `409`，不覆盖文件。当前导图的画布约每 4 秒读取最新已保存内容，包括助手提交的改动。

Word 与 Excel 的创建、导入由笔记页发给[文件库的办公笔记路由](../../../docs/subsystems/attachment.md#word-与-excel-文档快照)，读取、保存和下载由编辑器调用同一组路由。编辑器空闲时刷新磁盘快照，包括助手写入的改动。编辑器用 Host 返回的 `revision` 保存或导出；保存冲突时保留草稿，不自动覆盖磁盘上的内容。编辑区有独立于 Markdown 菜单的「导出」按钮，确认下载后先保存改动，再下载 `.docx` 或 `.xlsx`。

进入笔记页时，助手优先接续本次运行里在该页使用过的对话；没有则复用同目录的空白会话或新建，并启用笔记专用模式。重新打开窗口后的第一次进入停在带历史列表的助手欢迎页，带历史的旧对话在「最近对话」里手动接续。

页面约每 4 秒刷新目录树，活动 Markdown 被外部修改且没有未保存改动时采用新内容。首次读取只建立检测基线，未恢复标签时停在欢迎页。后续轮询发现助手新建导图或新建、改写 Markdown 时，仅在没有活动文档且没有创建请求的情况下打开最近写入的一篇；已有活动文档时，新导图只出现在目录，不切走当前标签。已有导图的修改由画布刷新，不触发目录自动打开。

目录初次加载并核对路径后，`usePublishNotesTabs` 在标签变更时发布完整快照，每 10 秒重发一次心跳；思维导图、Word 和 Excel 活动标签分别使用 `activeKind: 'mindmap'`、`'word'`、`'excel'`。同一窗口内重挂载沿用窗口标识并继续递增发布版本。来源校验与多窗口处理见[标签发布协议](../../notes/tool-notes-tabs/README.md#发布协议)。

## 导出

页头的导出入口只作用于当前打开的 Markdown 笔记，欢迎页上禁用，结构化文档不显示该入口。四种格式共用预览同一套 Markdown 渲染，字体固定为黑体，不跟随应用主题；导出前会去掉只属于界面的控件（代码块的横幅与复制按钮、KaTeX 的重复排版），代码块的语法高亮色也不带进文件，统一为白底深字。

- **Markdown（.md）**：保存原文，不改写内容。
- **Word（.docx）**：把整理后的 HTML 交给 `docx` 自带的 `docx/html` 转换器，标题、段落、嵌套列表、任务列表、引用、代码块、表格、链接与公式落到 Word 自己的样式上；正文字体由文档默认样式给出（`eastAsia` 黑体、西文 SimHei）。预览只把远程图片渲染成 `<img>`，Word 不联网取图，这类图片写成 `[图片] 替代文字`。
- **PDF（.pdf）**：按 A4 版心把正文切成连续若干页，逐页用 `html-to-image` 光栅化，再由 `jsPDF` 组装成 PDF 文件直接下载，不弹打印对话框。文字随页面成为位图，中文因此不依赖额外字库，代价是 PDF 内文字不能选中或搜索；需要可选中文本时导出 Markdown 或 Word。
- **图片（.png）**：`html-to-image` 把渲染好的白底正文画成 2 倍像素的 PNG；引用远程图片时受同源策略限制。

导出读的是编辑器里的当前草稿，不会为了导出先写盘。Word、PDF 与图片在生成期间禁用导出按钮，失败时提示「导出失败」并保留正文。

## 编辑与保存

格式工具对选区插入行内代码或待办列表，「插入表格」在光标处写入一张三列、两行空单元格的 Markdown 表格并选中第一个表头，编辑结果同步到 Markdown 预览。源码视图按代码编辑器的按键语义工作：`Tab` 在光标处插入一级缩进（两格），选中若干行后 `Tab`／`Shift+Tab` 逐行缩进或退回一级，`Home`／`End` 落在当前行首尾而不是跳到文首文末；焦点不会因此跑出输入区，`Cmd/Ctrl+Home`、`Cmd/Ctrl+End` 仍是整篇跳转。停顿 900ms 自动保存；`Cmd/Ctrl+S`、编辑器或窗口失焦、切换笔记也会触发保存。保存按读取到的修改时间检查冲突；保存失败时保留当前草稿，并暂停切换笔记。页头提供「重试保存」或「重新加载」；冲突时需要确认舍弃未保存改动，才读取最新版本。新建笔记通过模态框输入名称，由 Host 净化并补 `.md` 扩展名；新建幻灯片由 PPT 服务在笔记目录写出一份默认整稿的 `.codingppt` 工程目录，之后的编辑都落在该目录里；「导入 → 幻灯片」同样在该目录落盘，源 `.pptx` 不留在笔记目录；「导入 → 文本」把 TXT 与 Markdown 一样存成 `.md` 笔记。目录与幻灯片工程目录都由 Host 创建为私有目录并拒绝路径越界；删除幻灯片时连同其工程文件一起递归删除。

## 模型体验

界面不向模型请求直接注入内容；笔记页的对话与工作台中的对话共用同一会话日志与回放规则。已发布的标签、导图及 Office 笔记内容由[笔记预设工具](../../notes/tool-notes-tabs/README.md#model-experience)按调用读取。

#### KV Cache 影响

无；笔记页布局、视图和保存状态不进入模型请求。

## 已知限制与后续工作

- 文件管理的笔记条目只列出笔记根目录直属的 Markdown 文件；子目录里的笔记、思维导图及原生 Word／Excel 从笔记目录访问。
- 目录是有层级的完整树，按文件库的深度和节点上限加载，不分页；收起侧栏后不显示目录和笔记条目图标，只保留顶部的加号。
- 目录顺序由各目录的私有清单保存；清单缺失、损坏或被替换时回退名称排序，未记录条目排在已记录条目之后。移动若在磁盘改名后遇到同步或清单写入失败，Host 可能返回失败，客户端会刷新最新目录后提示，以磁盘实际状态为准。
- 每次重新打开窗口后的第一轮笔记对话都会新建一个会话，旧的留在欢迎页「最近对话」（按修改时间取前 3 条）与侧栏会话列表里。
