# coding-client-ui-notes

笔记界面：外侧窄导航的「笔记」入口、独立主内容页，以及完全复用对话的 AI 助手栏。

## 页面结构

笔记占用 `shell.page` 的 `notes` 键。页内目录复用 `SidebarRoot`，与对话侧栏共用宽度和折叠状态；目录行独立滚动，新建入口与目录标题同行，收起时仍留在图标轨顶部。中央顶栏展示已打开笔记的横向可滚动标签，目录项负责打开或选中标签，标签可切换或关闭；下方 `NotesDocument` 是活动文档的独立内容容器，头部提供标题、保存状态、导出与助手入口。Markdown 正文在「编辑／并排／预览」之间切换；PPTX 通过 `notes.document.ppt` 子 slot 复用 PPT 工作台，不进入 Markdown 草稿流程。中央实际宽度至少 640px 时默认并排；不足时隐藏「并排」，默认编辑，仍可切换到预览。视图切换不丢弃草稿。

未选中笔记时，正文显示插画、随本地时间变化的问候和一句说明，不重复显示新建入口。宽窗口默认并排打开右侧 AI 助手；窄窗口默认收起，可从页头打开抽屉。助手复用相同会话的对话，收起或改用抽屉不另建会话。并排呈现时助手与正文之间有一条可拖拽的分隔条，宽度偏好保存在根布局 store（默认 400px，范围 400–760px），正文至少保留 648px；空间不够时不动偏好，改用抽屉。助手页头的「新对话」按钮在同一笔记目录上新建会话，仍切到「笔记专用模式」，页面与助手保持在原位；新会话完成前重复点击被忽略，失败时保留当前对话与草稿。

页面通过 `shell.page` 的 store 记住活动笔记路径、已打开标签顺序与展开的目录；切到其他页面再回来、或重新载入窗口后恢复活动笔记与标签，正文仍从文件库重新读取，不缓存草稿内容。目录加载时移除已被删除的标签，删除或重命名文件／目录时同步其标签；关闭活动标签会选中相邻标签，最后一页关闭后回到欢迎区。切换或关闭活动标签先保存当前草稿，保存冲突或失败时留在原页并保留未保存改动。离开页面时先触发一次保存，回来后看到的是最新内容。新建会话从欢迎页开始，不继承上一个会话的浏览位置。

## 目录操作

目录标题旁的加号菜单提供「新建笔记」「新建目录」和「新建幻灯片」，默认保存到「全部笔记」；「新建幻灯片」创建可由 PPT 工作台打开并原位写回的默认整稿。目录行新建按钮和右键菜单只提供笔记、目录操作，打开弹窗时默认保存到该目录。「保存到」菜单把子目录逐级缩进，选择后显示完整位置；每一行（包括「全部笔记」）都有独立的「新建子目录」图标按钮，点击后在同一弹窗切换到以该行为父目录的目录表单。取消目录表单会返回原创建表单，保留名称和保存位置；创建成功后刷新目录树、选中新目录，并带着原名称返回原表单。目录刷新和正在编辑的笔记不会改变选中的位置。创建成功后展开父目录，让新条目可见。

侧栏展开时，行末默认显示修改日期；鼠标悬停或键盘焦点位于行内时，[`SidebarRootItem`](../ui-primitives/README.md) 在日期位置显示重命名和删除按钮，目录行同时显示新建笔记和新建目录按钮。右键菜单提供同样的操作。侧栏收起时隐藏行内按钮，标题加号仍可用。

从行内按钮或右键菜单发起删除都要先在弹窗中确认。弹窗说明删除不可撤销，并说明目录会一并删除其中的文件和子目录。取消不会发出删除请求；确认后立即开始删除，普通 Markdown 笔记按单文件删除，真实目录始终递归删除。失败时可在同一弹窗重试；成功后立即更新目录树，不等待下次定时刷新。删除路径仅限笔记根目录内，且不跟随条目符号链接。

## 数据源

目录树、Markdown 原文读写、目录操作来自[文件库](../../attachment/file-library/README.md)持有的笔记域（`~/.coding/files/notes`）；新建幻灯片走 PPT 宿主的 `/api/ppt/notes/create`，由 Host 生成并安全落盘 `.pptx`，页面随后通过一次 `source/open` 挂载工作台。页面只消费 HTTP 接口，不直接读写文件系统。进入笔记页时，助手用本次运行里已经打开过的那个对话；本次运行还没进过页面时，优先复用同目录里的空白会话，没有就新建，并切到「笔记专用模式」。所以重新打开窗口后的第一次进入停在带历史列表的助手欢迎页，带历史的旧对话只在「最近对话」里手动接续；页面开着时切到别的页面再回来则接续刚才那轮对话。助手能从该目录读、改和新建 Markdown 笔记。页面约每 4 秒刷新目录树；当前笔记被外部修改且没有未保存改动时会采用新内容。首次进入页面或新建会话后不自动打开任何笔记，正文停在欢迎页；用户点目录里的行才打开。当前没有打开文档时，刷新后若发现助手新增或改写过的笔记，就直接打开最近写入的一篇，正文显示写入后的内容；创建请求进行期间不抢先切换。

## 导出

页头的导出入口只作用于当前打开的笔记，未打开时禁用。四种格式共用预览同一套 Markdown 渲染，字体固定为黑体，不跟随应用主题；导出前会去掉只属于界面的控件（代码块的横幅与复制按钮、KaTeX 的重复排版），代码块的语法高亮色也不带进文件，统一为白底深字。

- **Markdown（.md）**：保存原文，不改写内容。
- **Word（.docx）**：把整理后的 HTML 交给 `docx` 自带的 `docx/html` 转换器，标题、段落、嵌套列表、任务列表、引用、代码块、表格、链接与公式落到 Word 自己的样式上；正文字体由文档默认样式给出（`eastAsia` 黑体、西文 SimHei）。预览只把远程图片渲染成 `<img>`，Word 不联网取图，这类图片写成 `[图片] 替代文字`。
- **PDF（.pdf）**：按 A4 版心把正文切成连续若干页，逐页用 `html-to-image` 光栅化，再由 `jsPDF` 组装成 PDF 文件直接下载，不弹打印对话框。文字随页面成为位图，中文因此不依赖额外字库，代价是 PDF 内文字不能选中或搜索；需要可选中文本时导出 Markdown 或 Word。
- **图片（.png）**：`html-to-image` 把渲染好的白底正文画成 2 倍像素的 PNG；引用远程图片时受同源策略限制。

导出读的是编辑器里的当前草稿，不会为了导出先写盘。Word、PDF 与图片在生成期间禁用导出按钮，失败时提示「导出失败」并保留正文。

## 编辑与保存

格式工具对选区插入行内代码或待办列表，编辑结果同步到 Markdown 预览。停顿 900ms 自动保存；`Cmd/Ctrl+S`、编辑器或窗口失焦、切换笔记也会触发保存。保存按读取到的修改时间检查冲突；保存失败时保留当前草稿，并暂停切换笔记。页头提供「重试保存」或「重新加载」；冲突时需要确认舍弃未保存改动，才读取最新版本。新建笔记通过模态框输入名称，由 Host 净化并补 `.md` 扩展名；新建幻灯片由 PPT 服务生成默认整稿并补 `.pptx`，后续编辑由工作台原位写回；目录由 Host 创建为私有目录并拒绝路径越界。

## 模型体验

界面不注入模型可见内容；笔记页的对话与工作台中的对话共用同一会话日志与回放规则。AI 助手对笔记目录的读写走文件工具链的常规路径，不产生新的模型输入。

#### KV Cache 影响

无；笔记页布局、视图和保存状态不进入模型请求。

## 已知限制与后续工作

- 子目录里的笔记只在目录树中可见，不会出现在文件管理的未分组列表（那里只登记笔记根目录的直属文件）。
- 目录是有层级的完整树，按文件库的深度和节点上限加载，不分页；收起侧栏后不显示目录和笔记条目图标，只保留顶部的新建入口。
- 每次重新打开窗口后的第一轮笔记对话都会新建一个会话，旧的留在欢迎页「最近对话」（按修改时间取前 3 条）与侧栏会话列表里。
