# coding-client-ui-notes

笔记界面：外侧窄导航的「笔记」入口、独立主内容页，以及完全复用对话的 AI 助手栏。

## 页面结构

笔记占用 `shell.page` 的 `notes` 键。页内目录复用 `SidebarRoot`，与对话侧栏共用宽度和折叠状态；目录行独立滚动，新建入口与目录标题同行，收起时仍留在图标轨顶部。中央页头显示选中笔记的标题和保存状态，正文可在「编辑／并排／预览」之间切换。中央实际宽度至少 640px 时默认并排；不足时隐藏「并排」，默认编辑，仍可切换到预览。视图切换不丢弃草稿。

宽窗口默认随笔记页打开右侧 AI 助手；窄窗口默认收起，可从页头打开抽屉。页头开关由根布局提供显隐状态和动作。助手复用相同会话的对话，关闭或切换呈现方式不会另建会话；笔记页不注册或实现对话视图。

## 数据源

目录树、原文读写和新建都来自[文件库](../../attachment/file-library/README.md)持有的笔记域（`~/.coding/files/notes`）。页面只消费 HTTP 接口（`/api/notes/*`），不直接读写文件系统。打开笔记页时复用以笔记根目录为工作目录的会话；没有时创建不挂工作区的会话。助手能从该目录读、改和新建笔记。页面约每 4 秒刷新目录树；当前笔记被外部修改且没有未保存改动时会采用新内容。

## 编辑与保存

格式工具对选区插入行内代码或待办列表，编辑结果同步到 Markdown 预览。停顿 900ms 自动保存；`Cmd/Ctrl+S`、编辑器或窗口失焦、切换笔记也会触发保存。保存按读取到的修改时间检查冲突；保存失败时保留当前草稿，并暂停切换笔记。页头提供「重试保存」或「重新加载」；冲突时需要确认舍弃未保存改动，才读取最新版本。新建通过模态框输入名称，由 Host 净化并补 `.md` 扩展名。

## 模型体验

界面不注入模型可见内容；笔记页的对话与工作台中的对话共用同一会话日志与回放规则。AI 助手对笔记目录的读写走文件工具链的常规路径，不产生新的模型输入。

#### KV Cache 影响

无；笔记页布局、视图和保存状态不进入模型请求。

## 已知限制与后续工作

- 子目录里的笔记只在目录树中可见，不会出现在文件管理的未分组列表（那里只登记笔记根目录的直属文件）。
- 目录是有层级的完整树，按文件库的深度和节点上限加载，不分页；收起后的图标轨显示已展开分支中的笔记，不显示目录展开按钮。
