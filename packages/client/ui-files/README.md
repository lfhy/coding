# coding-client-ui-files

「设置 → 文件管理」列出当前 Host 管理的全局上传文件和生成图片。分区仅在打开时请求 `GET /api/files/list?offset=<n>&limit=<n>`，每页最多 50 条；按 Host 返回的 `nextOffset` 加载更多，离开分区取消未完成请求。列表只呈现名称、类型、大小、创建时间和总数，不提供删除或写入操作，也不从浏览器直接读取文件系统。读取失败可重试；首次无记录显示空状态。

Host 根据配置解析 `~/.coding/files`，响应只包含相对路径和元数据，不包含绝对路径。未识别的响应记录会使这一页读取失败，不在界面展示原始服务错误或文件路径。文件准入、隔离及持久化由 Host 文件能力负责。

## 模型体验

本包不贡献模型可见内容。

#### KV Cache 影响

本包只读取文件目录，不改变模型请求与提示词前缀。
