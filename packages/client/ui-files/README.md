# coding-client-ui-files

外侧窄导航的「文件管理」进入独立主内容页，默认管理没有工作区的会话输入、生成图片和导出成品；页面只展示文件库元数据，不把本机绝对路径交给浏览器。页面以当前会话作为布局锚点，没有当前会话时会创建一个 Host 默认目录的空白会话，但不切换模式或发送消息。设置中的「文件管理」分区仍保留，用于查看设备级的全部文件。

主页面与设置分区都按打开时请求 `GET /api/files/list?offset=<n>&limit=<n>`；外侧页面追加 `scope=unscoped` 只返回未归属工作区的记录，每页最多 50 条。按 Host 返回的 `nextOffset` 加载更多，分页间总数变化时重新读取第一页，同一文件 id 只显示一次。离开页面取消未完成请求。列表只呈现名称、类型、大小、创建时间和总数，不提供删除或写入操作，也不从浏览器直接读取文件系统。读取失败可重试；首次无记录显示空状态。

独立页使用 `ui-primitives` 的 `SidebarRoot` 呈现文件分类；`shell.page` owner 提供的 `sidebarCollapsed`、`sidebarWidth` 与 `toggleSidebar` 和对话侧栏共用根布局状态及宽度偏好，页面切换不会重置折叠状态。

Host 根据配置解析 `~/.coding/files`，响应只包含相对路径和元数据，不包含绝对路径。未识别的响应记录会使这一页读取失败，不在界面展示原始服务错误或文件路径。文件准入、隔离及持久化由 Host 文件能力负责。

## 模型体验

本包不贡献模型可见内容。

#### KV Cache 影响

本包只读取文件目录，不改变模型请求与提示词前缀。
