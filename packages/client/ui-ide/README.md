# coding-client-ui-ide

外侧窄导航的「代码工作区」进入独立欢迎页。页面以当前会话作为布局锚点；没有当前会话时，在 Host 默认目录创建空白会话，只用于承载页面，不切换模式或发送消息。欢迎阶段隐藏共享 AI 助手，不渲染文件树或编辑器栏。

欢迎页提供「打开文件夹」与按更新时间排列的最近工作区。目录选择通过 `shell.ide.welcome.directoryFlow` 复用已装配的浏览式或原生选择包。选取目录后注册工作区、复用或创建空白会话，并关闭独立页进入该工作区的现有三栏视图。失败通过共享 Toast 告知，当前页面保留。

页面文案位于 `ide` 命名空间，样式使用 CSS Modules 与共享主题令牌。`shell.page` owner 负责会话、返回动作和页头生命周期；工作区与会话的创建、复用和选择归 `coding-client-runtime`。

## 模型体验

无。本包只贡献工作区入口和界面，不组装模型请求，也不写入会话日志。

#### KV 缓存影响

无；本包不发送提供方请求。

## 已知限制与延后工作

- 文件树、文件标签、编辑器、终端面板及工具调用联动尚未接入；当前只提供入口、欢迎页和既有工作区切换。
