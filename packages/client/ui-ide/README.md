# coding-client-ui-ide

外侧窄导航的「代码工作区」进入独立页面。页面以当前会话作为布局锚点；没有当前会话时，在 Host 默认目录创建空白会话，只用于承载页面，不切换模式或发送消息。

页面按当前会话是否已归属某个工作区呈现两种形态。未归属时显示欢迎页：提供「打开文件夹」与按更新时间排列的最近工作区，目录选择通过 `shell.ide.welcome.directoryFlow` 复用已装配的浏览式或原生选择包；此时隐藏共享 AI 助手。选取目录后注册工作区、复用或创建空白会话，并在同一 `ide` 页打开该会话并请求 `auto` 助手。已归属时显示三栏工作区：左侧是 `SidebarRoot` 文件树，中间是文件标签与文本编辑区，右侧第三栏由根布局的页面助手提供，本包只渲染页头的助手开关。

打开失败留在原页面并用共享 Toast 告知；Escape 先保存活动草稿，成功后才离开页面，草稿保存失败时保留页面。

## 工作区文件

文件树、读取和保存都经 `ctx.workspaceFiles`（由 [`coding-client-ui-open-in-app`](../ui-open-in-app/README.md) 提供的 Session 绑定协议）完成，本包不拼装 OS 路径：展开目录时才请求下一层，标签首次打开时才读取正文，读到的版本随草稿保留。

保存使用读取时获得的版本做条件写入。冲突（HTTP 409）保留草稿并提示重新载入；其它保存失败保留草稿并提供重试。关闭有未保存改动的标签、或在有草稿时重新载入，都要先经过确认弹层；页面失焦、⌘/Ctrl+S 与离开页面前也会尝试保存。二进制或过大文件只显示状态，不进入编辑。

标签顺序、活动文件、展开目录与已加载层级放在 `shell.page` 声明的会话级 store 中，切页后保留；文件正文只在内存中保留，不写入持久存储。页面文案位于 `ide` 命名空间，样式使用 CSS Modules 与共享主题令牌。

## 模型体验

无。本包只贡献工作区入口与编辑界面，不组装模型请求，也不写入会话日志；右侧助手沿用当前工作区会话的既有对话。

#### KV 缓存影响

无；本包不发送提供方请求。

## 已知限制与延后工作

- 只保存已存在的文本文件；新建、重命名和删除文件尚未接入。
- 不使用代码编辑器组件，编辑区是带行号的文本域，因此没有语法高亮、补全或诊断。
- 文件树不监听文件系统变更；外部改动只会在重新读取该文件时出现，并由版本冲突提示。
- 页内终端与工具调用联动尚未接入；需要它们时应由本包声明页内 slot，而非复用页面打开时隐藏的根底栏。
