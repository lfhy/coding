# coding-client-ui-ide

外侧窄导航的「代码工作区」进入独立页面。页面的工作区选择、打开的文件与编辑器分组都由本包自己持有，**与对话页当前会话及其工作区无关**：进入页面永远从欢迎页或本页上次停留的工作区开始，页内切换工作区不会改变对话页的原选择。外壳要求页面绑定一个会话，这个会话只作为导航锚点与右侧助手上下文；没有当前会话时在 Host 默认目录建一个空白会话承载页面，只用于承载，不切换模式或发送消息。

页面有两种形态。没有选中工作区时显示欢迎页：提供「打开文件夹」与按更新时间排列的最近工作区，目录选择通过 `shell.ide.welcome.directoryFlow` 复用已装配的浏览式或原生选择包，此时隐藏共享 AI 助手。选中工作区后显示三栏：左侧 `SidebarRoot` 上半部分是「打开的编辑器」，下半部分是项目文件树；中间是文件标签与文本编辑区（可分屏成多个编辑器分组）；右侧第三栏由根布局的页面助手提供，本包只渲染页头的助手开关。

页头标题右侧的「切换工作区」菜单列出最近工作区与「打开其他文件夹…」，切换只换本页的文件与助手上下文。

打开失败留在原页面并用共享 Toast 告知；Escape 先保存活动草稿，成功后才离开页面，草稿保存失败时保留页面。

## 工作区文件

文件树、读取和保存都经 `ctx.workspaceFiles`（由 [`coding-client-ui-open-in-app`](../ui-open-in-app/README.md) 提供的 Session 绑定协议）完成，本包不拼装 OS 路径：展开目录时才请求下一层，标签首次打开时才读取正文，读到的版本随草稿保留。文件可以从项目树拖到目标编辑分组的标签栏或编辑区，按单击文件的预览语义打开；有效落点显示「松开打开文件」与复制光标，拖拽结束、Escape 或窗口级 `dragend` 都会清理拖动态。拖拽只携带 provider 名称链，不拼本机路径。Host 侧按会话 header 的 cwd 提供服务（live 会话优先，其次是持久化 header），因此 Host 重启后尚未恢复的会话同样能列目录、读文件与按版本保存。

保存使用读取时获得的版本做条件写入。冲突（HTTP 409）保留草稿并提示重新载入；其它保存失败保留草稿并提供重试。关闭有未保存改动的标签、或在有草稿时重新载入，都要先经过确认弹层；页面失焦、⌘/Ctrl+S 与离开页面前也会尝试保存。二进制或过大文件只显示状态，不进入编辑。

## 页面状态与分屏

状态实例由插件在 `apply` 中创建一次，按工作区分别保存标签、草稿、展开目录、已加载层级与编辑器分组：切换工作区、关闭再进入代码工作区后都保留，文件正文只在内存中，不写入持久存储。切换瞬间被中断的目录与正文读取会在重新进入该工作区时补一次。

单击项目文件或「打开的编辑器」中的条目只激活已有标签，或用临时预览标签打开文件。每个编辑器分组同时最多保留一个预览标签，打开下一个预览文件会替换它；预览名称用斜体表示。双击预览标签或「打开的编辑器」中的预览条目会固定标签，固定后正常字体显示。预览一旦产生未保存修改也会自动固定，避免替换时丢失草稿。

标签可拖动：拖到另一个分组的标签栏把该标签移过去，拖到编辑区的左半或右半把标签拆成新的编辑器分组；页头「向右拆分」在当前文件的基础上再开一个分组同时显示同一文件。分组标签栏右侧的关闭按钮把该分组的标签并入相邻分组，合并时按路径去重；只拖唯一标签不会产生空分组。

页面文案位于 `ide` 命名空间，样式使用 CSS Modules 与共享主题令牌。

## 模型体验

无。本包只贡献工作区入口与编辑界面，不组装模型请求，也不写入会话日志；右侧助手沿用当前锚点会话的既有对话。

#### KV 缓存影响

无；本包不发送提供方请求。

## 已知限制与延后工作

- 只保存已存在的文本文件；新建、重命名和删除文件尚未接入。
- 不使用代码编辑器组件，编辑区是带行号的文本域，因此没有语法高亮、补全或诊断。
- 文件树不监听文件系统变更；外部改动只会在重新读取该文件时出现，并由版本冲突提示。
- 分屏分组不持久化：同一浏览器会话内跨工作区保留，刷新页面后重建；不提供拖动分隔条调整分组宽度。
- 页内终端与工具调用联动尚未接入；需要它们时应由本包声明页内 slot，而非复用页面打开时隐藏的根底栏。
