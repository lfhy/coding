# coding-client-ui-ppt-workbench

## 概述

右侧边栏的「PPT 工作台」标签在打开工程后提供可收起的左侧缩略图与主画布，可就地改字、拖动元素、增删页与导出；操作收纳在顶部胶囊，属性按需覆盖画布。本包也提供设置中的「PPT 模板管理」分区与工作台「更多」里的模板目录入口。工作台通过 `ctx.sidebarRightTabs.register` 注册成外部标签，内容注册到 `sidebar.right.pane.tab`（键为定义 id）；工程和模板目录数据来自宿主 `coding-ppt-workbench` 的 `/api/ppt/*` 路由。

## 行为

- **注册与出现**：标签类型 id 为 `ppt-workbench`、kind 为 `ppt`，`keepMounted: true`；不加入工作台功能菜单和共享 `+`。当前会话须使用 `ppt` 模式且首条对话已被接纳（`blank: false`），才会自动打开该会话的唯一标签；空白会话和其他模式不自动打开。每个会话只自动打开一次，手动关闭后不再弹开；工作台尚未挂载时按 300ms 节流重试，约 6 秒后放弃。
- **模板目录与对话交接**：设置分区与工作台目录展示[默认六页整稿](../../ppt/ppt-workbench/README.md#默认整稿与内置单页版式)的第一页预览、七种内置单页版式卡片及各自的真实预览，另列本机用户整稿模板、详情和第一页预览。默认整稿的「用默认设计创建」、单页卡片的「用此版式创建」、用户模板的「使用此模板」都只准备 PPT 会话草稿；单页草稿包含 `template: <版式 id>`，「导入 / 创建模板」填入「帮我生成PPT模版」。用户模板详情显示来源文件名和已知设计损失；目录只预览第一页，套用后应逐页检查，复杂图形和主题色不保证保真。工作台空工程与工程列表中的「模板管理」按钮、已有稿件的「更多 → 模板管理」打开同一目录。目录不上传文件、不调用模板写接口、不创建工程，也不自动发送消息。当前 PPT 会话已有草稿会保留并追加请求；其他已开始模式会在同一工作区新建空白 PPT 会话，不切换原会话的模式，也不劫持已有空白会话草稿。准备成功后关闭弹窗、显示对话并聚焦输入；关闭设置或目录会取消未完成的交接，失败或中途切换会话时不会迟到导航、写草稿或抢焦点。各预览和用户模板目录分别报错和重试；模板导入的来源限制与内容保真见[宿主契约](../../ppt/ppt-workbench/README.md#质检与导入)。
- **未打开工程**：当前无工程且工程列表为空时，工作台居中显示小幻灯片图标、「PPT 工作台」和「还没有打开的演示文稿。」，不显示编辑工具栏、新建表单和状态栏；已有工程可从列表打开，选择已有工程或通过对话创建、打开演示文稿后显示编辑器。
- **布局与操作**：左侧缩略图使用独立面板，顶部显示页数并可收起，页码位于各预览左侧；顶部标题胶囊显示工程标题、页数、修订与操作反馈，也可收起或展开缩略图。编辑胶囊提供「新增页面」「插入」「页面」菜单和撤销/重做，操作胶囊提供「属性」、质检、预览、导出及「更多」中的重新读取；「属性」以覆盖式面板显示元素、页面和文稿设置，可关闭或按 Escape 返回，不挤压画布。
- **会话级状态**：每个会话一个控制器，持有工程快照、当前页、选中元素、就地编辑目标与顶部反馈；同一会话的多个面板实例共享同一份状态。
- **轮询**：面板可见时每 3 秒读一次 `state`，隐藏即停。模型创建或打开工程后，宿主的会话状态已指向该工程；面板直接采用当前快照并确认打开请求，不重复打开。外部编辑的新版本在下一次轮询中同步到该会话的面板。
- **编辑**：双击文字就地改、拖动元素移动位置、拖八个手柄改尺寸；打开「属性」后可改字号/颜色/对齐/填充，并能复制元素与调整层级（置顶、置底、上移一层、下移一层）。每次操作提交一次 `ppt_edit`，之后用返回的快照刷新，不做本地乐观改写，所以显示的一定是宿主已落盘的版本。
- **画布右键**：右键元素可剪切、复制、粘贴或删除；右键图片、矩形或其上紧邻且完全重合的居中图片提示文字可选文件替换图片。矩形会原位变为图片，匹配的提示文字一并消失；普通正文不作为图片占位。空白处可插入文本框、矩形、椭圆、分隔线、图片、表格或图表。
- **元素**：文本框、矩形、椭圆、分隔线、图片（本地选文件上传到工程 `media/`；上传请求在查询参数传会话身份）、表格（插入 3×3 模板，属性面板可整表改单元格）与图表（柱状/折线/饼，插入时带示例数据）。图片经 `/api/ppt/media` 直接按原始字节显示；图表在画布上按系列颜色画 DOM 预览，真实图表由导出的 chart 部件承担。
- **字体与动画**：选中文本可填字体族名；元素可选入场、强调、退场与路径动画，页面可选转场；图表可切换堆叠、次坐标轴与组合（第二条系列画成折线）。
- **页面**：缩略图可拖拽排序，顶部「页面」菜单可上移、下移或删除当前页；「新增页面」菜单可选版式模板（空白、封面、章节页、要点页、双栏对比、数据表格、图表页、引用页），新页会按当前主题铺好元素；打开「属性」可给当前页选转场（无/淡出/推进）。
- **预览**：顶部「预览」按钮把每页渲染成 PNG，同时页面会出现在右侧「Agent 浏览器」标签里——预览走的就是这个浏览器面板，不另做一套画布。
- **质检**：顶部「质检」按钮跑一次规则检查，问题显示在可关闭的浮层中，error 与 warning 分色显示。
- **表格与快捷键**：双击表格单元格可就地编辑，`Esc` 放弃，失焦或 `Ctrl/Cmd+Enter` 提交；选中表格并打开「属性」后，仍可用制表符分列、换行分行的文本域整表修改内容。剪贴板只在当前会话的同一工程内使用，跨页可粘贴，切换工程即清空；画布聚焦且不在输入框编辑时，`Cmd/Ctrl+X`／`C`／`V` 剪切、复制、粘贴，`Cmd/Ctrl+D` 复制副本，`Delete`／`Backspace` 删除选中元素。
- **冲突**：写入带 `baseRevision`，别处的改动会让这次编辑返回 409；顶部标题胶囊以警告色说明当前版本，不覆盖用户的改动。
- **导出**：顶部「导出 .pptx」按钮导出，成功后在标题胶囊给出绝对路径。

## 使用本包

与 [`coding-client-ui-open-in-app`](../ui-open-in-app/README.md)（提供 `sidebarRightTabs` 与 `sidebarRight`）、`coding-client-locale`、`coding-client-runtime` 并排挂载，并确保宿主装了 `coding-ppt-workbench`。布局 owner 必须声明 `sidebar.right.pane.tab` slot；缺失时本包的内容座位不会安装，插件本身照常加载。

## 模型体验

无。本包不注册工具、不写会话日志，也没有内容进入模型请求。

#### KV Cache 影响

无；本包不发送提供方请求。

## 已知限制与暂缓工作

- 画布是 DOM 直渲：支持的六类元素（文本、矩形、椭圆、连线、图片、表格）所见即所得，图表与 SmartArt 不建模。
- 表格不支持行列增删；单元格样式跟随表级排版。
- 撤销/重做按「一次编辑一步」前进或后退，没有合并窗口。
- 图片不缩放不改色，原字节嵌入导出。
- 轮询而非推送：别处的改动最多延迟一个轮询周期才出现。
