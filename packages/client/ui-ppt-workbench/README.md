# coding-client-ui-ppt-workbench

## 概述

右侧边栏的「PPT 工作台」标签：缩略图、画布与属性面板三栏，就地改字、拖动元素、增删页与导出。它通过 `ctx.sidebarRightTabs.register` 注册成工作台的外部标签，内容注册到 `sidebar.right.pane.tab`（键为定义 id）；数据来自宿主 `coding-ppt-workbench` 的 `/api/ppt/*` 路由。

## 行为

- **注册与出现**：标签类型 id 为 `ppt-workbench`、kind 为 `ppt`，`keepMounted: true`；工作台 `+` 菜单里有一项「PPT 工作台」入口。`ppt` 模式的会话在成为当前会话时自动打开该标签——只在每个会话里尝试一次，用户手动关掉后不再弹开；工作台尚未挂载时按 300ms 节流重试，约 6 秒后放弃。
- **会话级状态**：每个会话一个控制器，持有工程快照、当前页、选中元素、就地编辑目标与底部反馈；同一会话的多个面板实例共享同一份状态。
- **轮询**：面板可见时每 3 秒读一次 `state`，隐藏即停。模型在别处新建或打开了工程时，面板跟随过去并回执；同一工程被别处改出新版本时，面板静默换成新版本。
- **编辑**：双击文字就地改、拖动元素移动位置、属性面板改尺寸/字号/颜色/对齐；页面可增删与上下移动。每次操作提交一次 `ppt_edit`，之后用返回的快照刷新，不做本地乐观改写，所以显示的一定是宿主已落盘的版本。
- **冲突**：写入带 `baseRevision`，别处的改动会让这次编辑返回 409；底部状态条改为警告色并说明当前版本，不覆盖用户的改动。
- **导出**：工具条按钮导出 .pptx，成功后在状态条给出绝对路径。

## 使用本包

与 [`coding-client-ui-open-in-app`](../ui-open-in-app/README.md)（提供 `sidebarRightTabs` 与 `sidebarRight`）、`coding-client-locale`、`coding-client-runtime` 并排挂载，并确保宿主装了 `coding-ppt-workbench`。布局 owner 必须声明 `sidebar.right.pane.tab` slot；缺失时本包的内容座位不会安装，插件本身照常加载。

## 模型体验

无。本包不注册工具、不写会话日志，也没有内容进入模型请求。

#### KV Cache 影响

无；本包不发送提供方请求。

## 已知限制与暂缓工作

- 只支持文本、矩形、椭圆与直线四种元素，画布是 DOM 直渲，不渲染表格/图表/图片。
- 页序调整用上移/下移按钮，未做拖拽排序；元素缩放通过属性面板输入，未做拖拽手柄。
- 撤销/重做按「一次编辑一步」前进或后退，没有合并窗口。
- 轮询而非推送：别处的改动最多延迟一个轮询周期才出现。
