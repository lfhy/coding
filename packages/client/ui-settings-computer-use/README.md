# `coding-client-ui-settings-computer-use`

**电脑操作**设置分区：把 Host 的 `computer-use` 设置命名空间接到设置导航，提供开关、后端选择、按应用授权、交互策略与三处数值上限。

## 这里会出现什么

分区只在 Host 服务了这个命名空间时出现，也就是本地 macOS 宿主；其他平台与没有装载电脑控制的部署显示一条说明而不留空表单。分区内容按重要性分层：

- **状态带**在最前，回答「模型现在能不能用这套能力」：开关状态、后端名与接下来的行为。
- **允许 Agent 操作本机应用**：关闭后工具消费方立即撤回模型可见的引导工具、技能与执行工具；已加载过技能的会话在重新打开后按会话日志重新取得执行工具。
- **运行方式**：内置辅助功能组件或外部驱动；选后者才出现驱动路径，且操作光标固定关闭，因为该后端不画独立光标。
- **应用授权**：允许所有应用的总开关，以及按 bundle id 的读取／控制授权列表；控制包含读取。
- **交互策略**：点击与键盘输入是否把目标应用带到前台、是否关闭坐标输入、是否绘制操作光标。
- **高级**：观察有效期、确认令牌有效期、单次动作超时与截图目录。
- 段落末尾固定说明 macOS 辅助功能与屏幕录制权限在哪里授予；工具调用会报告当前权限状态。

分区只暂存草稿，**保存**是唯一的写入点；每份草稿按字段写入，Host 的命名空间 revision 为写入设栅，因此与文档脱节的表单会被拒绝而不是覆盖并发变更。失败保留草稿并提示重试，**放弃修改**回到已存值。

## 写入

字段的形状与上下界在这里做一次提交前的收窄（屏幕上的错误提示来自这一步），最终校验仍由 Host 的 `computer-use` 设置分节拥有；客户端不复制宿主的授权判定，也不决定某次本机输入是否放行。

## 模型体验

无。该分区渲染浏览器配置 UI；它写入的值只通过电脑控制能力到达模型，其模型可见效应由 [`coding-computer-use`](../../../computer-use/computer-use/README.md) 与 [`coding-tool-computer-use`](../../../computer-use/tool-computer-use/README.md) 记录。

#### KV Cache 影响

无；该包既不组装也不发送提供方请求。

## 已知限制与暂缓事项

- **不显示实时权限与授权决定**——分区说明权限在哪里授予，具体状态由工具调用返回；把 macOS 权限探测与「打开隐私面板」搬进设置页需要新增 Host Remote 端点。
- **按应用授权只能编辑已有条目**——应用列表来自运行时而不是设置文档，因此新增条目需要手填 bundle id，不能从运行中的应用里挑选。
- **写入只覆盖分区里出现的字段**——例如 `helper.allowSourceBuild` 这类部署选项不在界面里，写入 `helper` 时按已存值保留。
