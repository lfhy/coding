# Word 与 Excel 笔记编辑器

在[笔记页](../ui-notes/README.md)打开 Word 文档或 Excel 工作簿，当前正文可直接编辑。编辑区独立滚动；保存、导出和格式工具固定在画布上方，可用键盘操作。界面使用笔记页的亮暗设置，并支持中文和英文。

## 编辑与导出

Word 在正文中直接输入和选择文字，支持正文、标题和一至三级标题、段落对齐，以及加粗、斜体、下划线、删除线、文字颜色和字号。Excel 在单元格或公式栏输入数据，按 Enter 提交单元格；支持多个工作表、文字、数字、布尔值、本地公式以及可表示的公式缓存。单元格可设置文字样式、文字和填充颜色、数字格式及合并区域。

格式工具栏按桌面办公软件的习惯分区，分区之间以竖线分隔：撤销与重做｜文字样式｜段落样式｜对齐｜字号｜颜色（Excel 为数字格式｜颜色｜合并）。图标按钮悬停时显示名称；带下拉箭头的按钮展开列表，颜色按钮展开常用色板，点「更多颜色…」可输入自定义十六进制色。按下工具栏按钮不会移走画布焦点，当前选区保留给随后的格式动作。

Word 正文宽度跟随画布，左右各留一段空白，页面因此始终是整页可见、没有横向滚动条；两侧空白露出画布衬底，正文才有纸张边界。鼠标移到段落左侧时会显示段落柄；悬停片刻或点击它展开段落菜单，可插入列表、表格等块。Word 笔记保存的是编辑引擎的完整快照，因此表格、图片、链接这些块会随笔记一起落盘，重新打开时原样还原。

画布底部是 Univer 的页脚：左侧是当前字数，右侧是缩放控件（可拖滑块或点加减按钮，默认 100%）。缩放只改变查看比例，不改动内容。

正文提交到画布后自动保存，也可以点击「保存」或按 `Ctrl+S`／`⌘S`。保存使用最后确认的修订号。另一个窗口或助手更新了同一文档时，不会替换有修改的画布：打开「处理版本冲突」，可以返回继续编辑、确认丢弃草稿并载入最新版本，或明确确认使用草稿替换已读取的最新版本。再次冲突必须重新读取和确认。仅在画布没有未保存修改、单元格不在编辑中、页面可见时，轮询才采用助手或其他窗口的新内容。

选择「导出」，在确认框里点击下载。编辑器先结束当前单元格编辑，并等待提交到画布的修改保存成功，然后按 Host 确认的修订号下载 `.docx` 或 `.xlsx`。文件在两次操作之间更新，或保存未成功时，不下载旧版本。下载名称沿用笔记名。

## 装配与边界

本包没有配置项。浏览器入口通过 `ctx.slots.inject` 等待 `notes.document.office` 声明，按会话、路径和类型挂载一个编辑实例；隐藏、切换或改名都会释放旧实例和请求。草稿只保留在该会话和原路径的内存中，重新打开后需要手动保存或继续编辑，不自动写到改名后的路径或另一个同名文件。Host 已执行的写入不会因取消响应而回滚。

只使用 Apache-2.0 的 [Univer Docs Core](https://docs.univer.ai/guides/docs/features/core) 和 [Sheets Core](https://docs.univer.ai/guides/sheets/features/core) 1.5.0 预设。画布在本地运行，未启用商用扩展、云转换或遥测传输。读取、保存和 Office 导出仅使用[文件库同源接口](../../../docs/subsystems/attachment.md#word-与-excel-文档快照)；浏览器不加载 Host 运行时。

Word 画布替换了 Univer 文档的渲染控制器，让连续布局按容器宽度排版并预留左侧段落柄区域；替换发生在 Ready 阶段之前，依赖项依赖 Univer 内部的受保护方法，升级预设时需要重新核对。预设样式只作用于本编辑器的画布和它创建的浮层容器，不影响页面其它部分。段落柄、块菜单和悬停说明都是 body 直属节点，样式靠在 body 上加宿主类名圈定，而 `@scope` 的规则不匹配作用域根元素，浮层容器自身的工具类由 [`office-scope.ts`](src/client/office-scope.ts) 另行补充；漏掉这层补充会让浮层留在文档流里撑高整页，引出页面滚动条。

## 验证

运行 `pnpm exec vitest run packages/client/ui-office/tests` 检查格式、版本冲突、切换与导出时序；真实工作台的创建、助手更新和 Office 往返使用 [Web 办公笔记测试](../../../apps/web/tests/notes-office.e2e.ts)。

## Model Experience

无直接影响；浏览器编辑器只更新笔记内容，不向模型请求提供正文或新增工具。

#### KV Cache effect

无；本包不组装或发送模型请求。

## Known Limitations and Deferred Work

富文本粘贴只接收纯文字。Word 笔记保存引擎快照，表格、链接等块随笔记落盘，导出 `.docx` 时表格会写成真正的 Word 表格。当前预设不含绘图插件，编辑器还不能插入图片（快照里也不会有图片）；图片导出通道已就绪，接入绘图插件后即可生效。助手按段落读写时不会改动表格，含表格的文档会拒绝按段落编辑，避免重建正文丢掉结构。Excel 的手工调整行列大小、冻结、边框和未展开的共享公式不属于原生格式。格式工具只提供能保存的动作。关闭窗口不保留未保存草稿。Excel 单元格中的公式由本地计算引擎处理，Host 会拒绝对外部数据的引用及未支持的函数。
