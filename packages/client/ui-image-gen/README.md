# coding-client-ui-image-gen

图像生成的浏览器界面：设置里的「图像生成」分区、侧边栏「新对话」下方与画图会话页头的入口，以及主内容「工作台／灵感／图库」页面。工作台参照[上游页面](NOTICE.md)的最近生成、预览、生成面板与结果操作布局，使用本客户端的 slot、图标和主题样式；图像字节、图库记录与画布文档由[图像服务](../../image/image-gen/README.md)按会话持久化。本包可独立不装配。

## 使用与设置

在「设置 → 图像生成」配置 `image-generation` 命名空间；界面只支持 OpenAI 兼容协议，输入服务地址、模型和 API 密钥，不提供虚构的上游类型选择。`enabled` 默认 `false`；`endpoint` 和 `model` 默认为空；内部 `apiKeyRef` 默认为 `IMAGE_GEN_API_KEY`，已有自定义引用继续使用。服务地址接受任意 HTTP(S) 主机，禁止内嵌凭据、查询和片段。本机地址可以勾选「无需 API 密钥」，将 `apiKeyRef` 保存为空；关闭此选项使用已有引用或默认引用。密码框留空表示不更改密钥，环境变量或只读凭据不可在此改写。一个「保存设置」在已启用服务的地址、模型或鉴权引用改变前先停用生成，再持久化非机密字段、把非空密钥送到 `credentials.set`，最后恢复启用状态；配置变更失败时保持停用并保留未完成的表单草稿供重试，已保存字段不会重复写入。设置镜像只保存引用与 `credentials.describe` 返回的存在性、可写性；其他标签页更新当前引用的凭据或连接恢复后会重新读取，画图入口随可用性显隐。地址、模型或所需密钥缺失时开关自动禁用，其他配置字段仍可保存；已保存的启用偏好只有配置完整时才显示为开启。既有画廊图片仍可浏览。服务尚未启动时界面保留可重试的空态与已有记录，不显示原始错误。



画图入口只在图像服务已配置并启用（地址、模型与所需密钥齐全）时渲染：侧边栏「新对话」下方独立整行与 `image` 会话页头图标；欢迎页右上角没有重复入口，新会话的画图模式选项也只在服务可用时提供。点击入口时，无会话先建立空白会话；现有空白会话切换到 `image` 预设；已开始的其他模式会话先建立新的空白会话，不改写其历史。Host 确认预设后打开会话，再由 `ctx.layout.togglePage('image-gallery', sessionId)` 在侧栏右侧展示主画廊；再次点击侧栏入口或按 Escape 可返回对话。仅选择模式不打开画廊，也不开始模型轮次。切换或移除当前会话会关闭画廊，原会话输入与工作台子树不销毁。画廊可见时每三秒刷新目录，离开后取消旧请求；手动生图成功后立即读取权威目录。

主画廊顶部是与对话页同构的「工作台／灵感／图库」胶囊切换；图库内的「收藏」筛选可查看图片与灵感收藏，不占独立子页。图库支持搜索、比例筛选、排序和可增量展示的图片网格；卡片可预览、复制 Prompt、下载、收藏、继续编辑或放入画布。收藏和隐藏是浏览器本地的逐会话显示偏好：隐藏不删除持久 Session 图片事件或附件，管理确认明确说明这一点。工作台右侧切换文生图与图生图；图生图从最近生成列表拖入本会话图片，或导入本机参考图，Host 经附件准入后把它归入同会话图库，再将 ID 交给编辑接口。比例选择支持 `Auto · 自动` 与 Host 配置的比例，并与「生成质量」排在同一行；生成质量默认为「渠道默认」，可选「自动／低／中／高」，选定档位后发送 `quality`，图生图同样传参。图生图最多可使用十张参考图，添加按钮只显示加号。中心默认是图片预览，进入时按可用区域完整适配；「本次结果」工具栏提供适应窗口、缩放、新建、全屏、继续编辑和再次生成，生成期间预览区和提交按钮显示旋转加载状态，完成后同栏显示本次生成耗时，下方提供收藏、复制图片、下载及从本机图库隐藏；再次生成先将原描述和已有参数填回表单。灵感页包含原项目固定版本的两套案例元数据共 976 条，支持搜索、分类、收藏、复制 Prompt 和带入工作台；缩略图按原来源版本在线加载，不打包原图。

## 对接与限制

界面经同源 `/api/image-gen` 使用 `GET /state?sessionId`（含非机密尺寸表和参考图上限）、`GET /gallery?sessionId`、`GET /image?sessionId&id`、`POST /import?sessionId`、`POST /generate`、`POST /edit`、`GET /canvas?sessionId` 和 `PUT /canvas?sessionId`。参考图上传只提交原始 File，不在浏览器裁剪或把 base64 写入设置；Host 校验媒体类型、大小、动画和会话归属。画布写入携带 `{revision,state}`，文档为 `{version:1,nodes}`。节点按顺序绘制：笔迹为 `{id,type:'stroke',points:[{x,y}],width,color:'ink',erase?}`；图库图片为 `{id,type:'image',imageId,x,y,width,height}`。坐标使用固定画布像素，画布只保存节点，不跨会话引用图片。Host 限制节点数量、坐标、总字节与原图归属；目录 API 尚无服务端分页。

## 模型体验

本包不注册模型工具或修改提示词；画图和编辑的模型可见事件由 [图像服务](../../image/image-gen/README.md) 持有。画廊页面的手动生成请求不会新增对话消息。

#### KV Cache 影响

本包没有模型请求，画廊和画布操作不影响 KV Cache；会话输入仍按所选预设的普通模型路径执行。

## Known Limitations and Deferred Work

- 图库 API 暂无服务端分页；视图限制已挂载图片数量，但目录仍全量读取。
- 画布只持久化单页笔迹和画廊图片，不提供复杂图层、无限画布或撤销历史。
