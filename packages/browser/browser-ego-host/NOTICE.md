# 第三方来源与改造范围

本包移植 [Fisfzy/dsh-ego-browser](https://github.com/Fisfzy/dsh-ego-browser) v0.9.7、commit `50d3d8782521904af12157a0399bf563a8130299`（MIT，版权声明见原样保留的 [LICENSE](LICENSE)），其中嵌入 [CitroLabs/ego-lite](https://github.com/CitroLabs/ego-lite) 的 Linux CDP 移植与 ego-browser SDK（MIT，版权与嵌入依赖声明见 [上游第三方说明](THIRD_PARTY_NOTICES.upstream.md)）。本包保持 `runtime/ego-linux/`、`runtime/ego-browser/`、`bin/ego-cast-worker.mjs` 与 `third-party/upstream/src/` 的原语言；`third-party/upstream/lib/index.js` 是上游 Host 源码的单文件构建产物，生产运行时只加载该产物。`third-party/host/` 是早期的审阅用快照，不参与导入或生产打包执行。没有移植上游 Web UI、扩展配对、login import 或 FFmpeg 安装服务；上游声明中这些能力不等于本包已提供或下载相应二进制。

本包本地改动：`runtime/ego-linux/src/tabs.mjs` 删除空空间回退全局 tab；`runtime/ego-linux/src/task-spaces.mjs` 强制 isolation mode 创建失败时 fail-closed；`runtime/ego-linux/src/paths.mjs` 支持显式 `EGO_LINUX_STATE_DIR`；`runtime/ego-linux/src/chrome.mjs` 记录启动意图并在复用前与配置模式核对（不一致时替换实例，旧状态无意图字段时替换一次），并把默认窗口尺寸从 1280×900 改为 2560×1080（Xvfb 虚拟屏幕同步）；`runtime/ego-linux/src/shim.mjs` 与 `bin/ego-browser.mjs` 传递该意图，且 `--open` 明确跳过核对，使手动打开的窗口不会被下一次工具调用关掉；`bin/ego-cast-worker.mjs` 增加仅本机 loopback `/api/frame?targetId` 单页 JPEG 快照供受控 Host 转发；`third-party/upstream/src/config.ts` 兼容本仓 schemastery 缺少 `volatile()` 的构建，并把 `cdpMaxWidth` 的默认值与上限改为 2560、`third-party/host/worker/` 同步该范围后重建 `bin/ego-cast-worker.mjs`；`third-party/upstream/src/index.ts` 暴露按当前设置计算的浏览器进程环境供宿主复用、使用完整 Session id 的 SHA-256 作为任务空间名、把挂载期误触发的 `--stop` 修正为卸载清理、并只在启用 ffmpeg 后端时探测视频依赖，另新增 `headless`（默认开）与 `cursorName`（默认 `Agent`）两个设置及其环境变量注入、`ego_click`/`ego_hover` 的 CSS 穿透回退、`ego_tabs` 的目标校验与脚本去重声明；对应的 `third-party/upstream/lib/index.js` 已同步同样改动（该文件没有构建脚本，只能与源码同步维护）。新建的 `src/` 为 Coding 自有 Host 桥，按会话身份收口工具和 HTTP，不修改第三方原有许可。上游 `THIRD_PARTY_NOTICES.upstream.md` 中提到的 FFmpeg/GPL 是未移植下载机制的历史声明；本包默认只用 CDP，不分发 FFmpeg 可执行文件。
