# browser-electron

`coding-browser-electron` 仅在桌面 Host 中替换 `ctx.browserUse`；同一个 Electron guest 同时承接工作台人工操作和 Agent 命令。Web/CLI 仍由 [Playwright 提供方](../browser-playwright/README.md)拥有。桌面主进程先在 `127.0.0.1` 绑定私有 WebSocket，再启动 Host；插件配置 `originEnv` 和 `tokenEnv` 是环境变量的名称，不含端口或凭据。Host 通过 `Authorization: Bearer` 连接，令牌不会进入 URL、插件配置或只读画面。

模型操作从审批到执行结束独占会话；人工操作按会话排队，并在命令发送前执行准入复核。审批目标由主进程即时刷新；页面自行导航通过状态事件撤销旧截图与审批修订版。人工 `open-url` 和 `navigate` 在本次目标主 frame 的 `did-navigate` 提交并核验目标 URL 后即可返回，不等待顶层 DOM ready、严格 DOM 观测或截图；`loadURL` 完成也可作为就绪结果，缓慢子资源不会单独阻塞。主进程从原生加载事件发布可选的 `BrowserTabSummary.loading`，使地址栏在人工命令返回后仍显示加载状态，直到 guest 停止加载；Web 等提供方可不提供该字段。模型 `execute` 的导航在顶层 DOM 就绪后进行严格观测，不等待缓慢子资源完全加载；如果页面或 CDP 尚未就绪，仍按导航超时处理。原生导航在各自就绪条件下超过 10 秒仍未完成时，主进程尝试停止加载，并在 3 秒内确认旧导航停稳。停稳后，如果模型导航的目标主 frame 已提交且仍是当前页面，返回新的严格观测；否则保持失败，使旧观测与审批失效：已有页面的人工 `navigate` 或模型导航保留 guest，下一次单独获批的 `browser_snapshot` 可读取当前页面；`open-url` 则回滚并关闭本次新建的标签。无法安全停稳只关闭受影响的 Session。Host 私有桥的 20 秒请求超时、取消或连接断开仍终止整个连接并清除会话缓存；当前 Host 进程不自动重连，也不改道至另一提供方。每次连接最多保留八个会话，每会话最多八个标签页，PNG 最多 2 MiB；跨进程字段均受校验。主进程在协议的 `lease`/`release` 期间阻止未经授权的人工变更，并在 `execute` 时再次校验 `expectedTarget`。

审批目标的 `expectedTarget.stateRevision` 是主进程私有的目标修订版，独立于 UI 状态修订版：观测发布、标题变化等非目标状态更新不会单独撤销审批，导航、标签选择、视口变化与真人输入会撤销审批。元素 `ref` 只按「这次点击的含义」复核：节点身份、语义属性（`role`／`id`／`type`／`href`／`ping`／`target`／表单与提交语义／禁用与只读）、目标子树内的事件处理器、从目标到文档的祖先链事件处理器与重挂载、目标离开文档或换到另一个表单，以及输入时刻的可见性、禁用状态与命中位置。`class`、`style`、`data-*` 等展示性属性、子树文本与兄弟分支的内容更新不再使引用失效：实时页面一直在重渲染，按整棵属性快照比较会让引用几乎永远过期，遮挡与移位由命中测试兜底。观测只列出此刻可点击的元素，被遮挡、位于 `inert`／`aria-disabled` 子树、视口外或 `pointer-events: none` 的目标不进入 `Elements:`；拒绝点击或填写时错误消息点名原因（被谁遮挡、隐藏、禁用、移出视口或身份变化），调用方据此决定重拍快照、滚动还是换目标。

guest 的截图在主进程使用 Electron `nativeImage` PNG 编码器和[共享 `fitImage` 策略](../../attachment/attachment/README.md)满足 2 MiB 的桥接／预览预算；已合规的原图保持原样，超限画面等比缩小，仍无法纳入预算时拒绝该次观测。真人看到的原生 guest 不因截图缩放而变更视口；显式 `browser_screenshot` 的最终模型限额仍由[附件提供方](../../attachment/attachment-local/README.md)在持久保存时判断，不会提前用 2000px 裁掉预览。

模型租约期间已呈现的 guest 保持可见，由主进程拥有的独立透明原生视图接收人工输入并显示虚拟鼠标与渐隐移动轨迹；减少动态效果时直接定位并保留静态操作反馈。该视图不进入 guest DOM、元素引用或截图。工作台隐藏、切页或出现模态框时，guest 从 Host 撤下，输入屏障和指针窗口卸载；后台模型操作使用下述隐藏承载。点击与输入先显示鼠标移动，再复核元素身份、命中位置和审批目标，复核失败不发送输入；滚动同样复核页面与审批目标。工作台改变呈现尺寸仍使旧观测与目标令牌失效；Agent 占用提示不改变工作台画布尺寸。

人工 `open-url` 是单次按 Session 排队的开页操作：先校验 URL，再创建并选中新标签、等待上述导航就绪；没有会话时直接使用首个标签。成功返回新页面所在的活跃标签状态，观测和截图可留待后续模型操作；若主进程先发布同代、同活跃标签的较新状态，Host 返回该状态且不覆盖它；标签切换、浏览器代次变更或会话关闭不能作为本次开页成功。失败时关闭刚建的标签并恢复原活跃标签，无法安全停止的导航超时则依照上述规则关闭受影响的 Session。弹窗与权限限制同样作用于新 guest。

模型操作在页面未呈现或工作台隐藏时仍可读取 DOM、点击与填写。后台操作把普通 `WebContentsView` 挂载在管理器私有、永不显示、不可聚焦且忽略鼠标的 `BaseWindow` 内，保持完整视口，并在每次观测前恢复隐藏绘制；前台呈现移动同一个 guest，不把后台页叠到 Host 页面上方。移动不替换页面或临时 partition，也不改变元素引用的隔离与复核规则。显式 `browser_screenshot` 在未呈现的 guest 上也会通过 CDP 捕获当前页面。普通导航和快照在页面从未呈现时不附带 PNG，工作台首次显示后其余观测可附带 PNG。所有截图均受相同的 2 MiB 限额；CDP 截图超过 5 秒未返回时，只关闭受影响的 Session，迟到结果不能发布，不会因为页面在后台就改用其他浏览器。

同时挂载 `webServer` 与 `connection` 时，本包提供只读 `/browser-use/state`、`/browser-use/frame`，保持 Playwright 提供方的状态码、截图版本和环回同源入站限制。没有 Web Host 服务时不注册路由。此包不直接写入模型上下文；模型结果仍由浏览器工具消费方记录。无法连接桌面主进程时返回 `BROWSER_UNAVAILABLE`，不启动独立浏览器。

## Model Experience

本包不直接提供模型上下文；模型间接通过[浏览器工具消费方](../tool-browser/README.md)取得观测。

#### KV Cache effect

提供方不修改模型请求；仅已记录的工具结果影响后续模型上下文。

## Known Limitations and Deferred Work

原生导航与截图超时按上述单 Session 规则处理；私有桥请求超时、取消和连接断开会终止此 Host 进程的全部桌面浏览器会话。
